# ADR-043：离线棋盘反馈音效

- 状态：已采纳（2026-11-03）
- 关联：F28、B23、M4-06、E36/E37

## 背景

参考站有走棋音效与选子音效开关。其走棋更换器另有原生音效、随棋子皮肤、本地导入等功能，但不应将参考站资源放进产品。当前切片只交付两个本地事件。

## 决策

应用层 BoardFeedbackController 监听 BoardSession 的棋子选中变化与同一文档内位置修订，经 AudioFeedbackPort 请求播放；Flutter View 不直接调用插件。走棋/选子两个版本化本机布尔偏好默认开，关闭只静音相应事件。每次应用只负责一个短音效玩家，两个独立播放器允许落子音效不截断上一步的选子音效。

音频使用 audioplayers 6.8.1 平台适配器；两条短PCM WAV由仓库中的纯Dart生成器原创生成、随Flutter bundle本机读取。只播放已提交的移动，不播放非法/取消输入；新文档替换不发声音。播音失败捕获并静默降级，不能回滚棋谱或打断引擎。资源、依赖版本、lock摘要和支持边界见法律清单/追踪记录。

## 已知限制

当前只区分选子和通用位置变化，不识别将军、将死、吃子；所有提示音是简单合成音，不是用户可选音效方案。自定义音源导入/删除/安全上限、试听、系统语音和非macOS真实平台仍待后续。上游macOS插件会在当前Xcode报告Swift并发隔离警告，虽非构建失败，发行前须复查。

## 验收

纯Dart控制器测试确认开关、异常隔离和新文档静音；组件测试确认app连接声音端口/偏好；macOS集成测试真实加载asset并经原生插件启动两种合成音。该测试不替代人工主观听感或其它OS验证。
