# 审计缺口与关闭条件

原始调查时尚无业务实现；当前已有本地棋盘/保存/AI/编辑，实现在CURRENT_STATE与TRACEABILITY记录。下表只记录证据缺口，不能从产品范围删除；已有局部证据不等于关闭整项。

| 缺口 | 下一条可复现路径 | 关闭条件 |
|---|---|---|
| 登录后功能 | 取得合法测试账号后分别访问我的棋谱/错题/同步 | 读写、批量、搜索、目录、冲突、离线流程证据；远端写入另按任务授权 |
| 设置深层选项 | 设置→棋子更换/规则/语言/高级/关于 | 枚举每个选项、单位、默认、最小最大、非法值、重启持久化 |
| 对弈状态 | 首页→执黑→走棋→立即出招/变招/悔棋→双AI | 逐项记录边界、互斥、终局、取消中的迟到结果 |
| 编辑校验 | 编辑→清空→删除将帅/将帅照面→完成 | 提示与可提交性、撤销/取消、棋子数量限制 |
| 输入导出 | 逐格式合法/损坏/大文件/分支注释 round-trip | 原始样本自制且可授权，保留日志；图片识别成功率另测 |
| 复盘 | 合法棋谱→着法详情/局势/整谱分析 | 分支、删除、提升主线、注释和评分阈值逐项确认 |
| 云库 | 云库 tab→命中/无结果/断网 | 超时、重试、排序、自动落子、来源与隐私 |
| 手机和桌面 App 差异 | 手机视口审计、真实设备、官网桌面说明 | 触控/手势/权限和桌面专属能力单列，不能混作网页功能 |
| 参考版本变化 | 每个里程碑开始复查主页与菜单 | 新增/移除记录日期，保留旧编号 |

未知项阻止“完整对标”声明，不阻止推进独立离线模块的后续设计。B01 负责继续审计；本次第一轮调查已交付，不声称全面审计已闭环。
