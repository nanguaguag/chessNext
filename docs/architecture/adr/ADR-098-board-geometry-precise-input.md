# ADR-098：棋盘格网边距精确数值输入

- 状态：已采纳（M4-66，本机交互P）
- 日期：2026-11-05
- 关联：F21、B24、M4-58/62、E64–E77、ADR-090/094

## 背景

棋盘显示设置已有四边百分比滑杆和双格点拖动预览。四边滑杆步进0.5%，提供键盘/读屏操作，但用户不能直接输入精确值。源站边距是另一套未知单位和耦合几何：E76/E77观察到局部端点及不对称联动，尚未建立完整算法。不能把其0–500/0–550数值转换为本机百分比。

## 决策

- 在四边滑杆旁增加百分比数字输入，支持一位小数；仍以`BoardSkinGeometry`的项目模型作为唯一校验来源。
- 提交时按当前字段合法区间钳制。区间由1%–99%边界及横/纵最小55%跨度计算；非法或非有限输入恢复当前值。
- 输入更新与滑杆/拖点一致，继续经现有棋盘皮肤或偏好控制器保存；禁用加载期间的输入。
- 保留滑杆、拖点和恢复默认入口。具体控件形式、百分比单位及边界为项目P，不声明源站等价。

## 验收

1. 可通过键盘输入一位小数，并提交到当前棋盘皮肤。
2. 越界输入会按动态边界钳制，不破坏最小跨度。
3. 每个编辑入口共享同一几何、持久化和主棋盘投影。
4. 根测试串行、analyze通过；macOS复用既有实例验证同步，不启动新App。

## 未解决

源站真实单位、全局联动公式、所有输入舍入/焦点行为与保存生命周期仍U。M4-66只补本机精确输入，不关闭F21/B24。
