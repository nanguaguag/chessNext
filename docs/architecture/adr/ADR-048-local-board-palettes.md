# ADR-048：本机棋盘配色预设

- 状态：已采纳（M4-12）
- 需求：F21 / B24
- 证据：E41、E42

为先交付离线可用的棋盘外观能力，项目提供两个原创本机预设：宣纸木色（默认）和松石青。它们通过稳定枚举写入schema1偏好，无在线资源、上传或额外依赖。材料色角色包括底色、格线、河界题字、棋子面与边框；选择/焦点/目标状态保持独立可辨。

同一BoardDisplayScope将配色传递到主棋盘、局面编辑器和图片/GIF冻结快照。旧设置缺省仍为宣纸木色，未知枚举由既有安全偏好解析拒绝。UI仅支持预设选择；自定义图片、ZIP/目录导入、本机皮肤清单、编辑器和在线皮肤服务另由B24跟进。

参考站素材不进入应用。目标测试验证序列化兼容/竞态、选择后即时色值、重启还原与PNG/GIF快照捕获；仓库全量门槛和macOS启动见TRACEABILITY及SESSION_LOG。
