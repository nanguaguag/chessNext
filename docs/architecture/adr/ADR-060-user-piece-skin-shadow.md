# ADR-060：用户棋子皮肤独立阴影

状态：接受（2026-11-04）

## 背景

M4-20已让圆章/方章两个内置预设各自保存阴影。M4-22之后的用户皮肤仍读取其基础预设阴影，切换用户项无法保留各自的阴影调整。参考站E43确认存在无/柔和/明显及方向、距离、模糊、浓淡控件，但精确值域、阴影算法和保存/应用/导出成功仍未知。

## 决策

- 把平台无关的`PieceSkinShadow`值对象放入ports目录，用户皮肤定义可选保存它；既有JSON没有该字段时按基础预设阴影兼容读取。
- 新建用户皮肤时从当前用户项复制阴影，或从当前内置预设复制其阴影。
- 阴影设置对内置皮肤继续写入`AppPreferences.pieceSkinShadows`；对用户皮肤写入其独立定义。主棋盘、局面编辑器、PNG/GIF快照均解析所选用户项阴影。
- 阴影项目值域继续使用ADR-056的P定义：方向0°–359°，距离/模糊0%–20%格宽，浓淡0%–100%。不声称这些边界来自参考站。

## 后果

用户皮肤阴影不会覆盖其基础预设或其它用户项；旧皮肤目录可继续读取。网站阴影的真实边界/算法、用户皮肤导出与导入兼容仍为U/待办。
