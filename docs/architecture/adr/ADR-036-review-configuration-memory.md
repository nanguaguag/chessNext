# ADR-036：复盘方式独立偏好与单次跳过意图

2026-11-02，E12/E32。参考站模式选择取消后保留，重新分析skip每次默认关已V；首次采样skip开只是O，非清洁默认。项目保留首次配置skip开，有任何已完成评分结果（包括部分/stale）时默认关；用户显式开仍可复用同身份/历史/预算缓存。startReview应用API默认和缓存键无变化，不把展示默认改成算法策略。

reviewMode是AppPreferences可选schema1枚举best/candidates，旧字段缺省best，非法类型/名称拒绝。PreferencesController独立字段编辑合并/串行持久化/重试，改变方式不影响资源配置或任务。ReviewOptionsDialog在打开时读取方式并立即保存选择，取消仅不提交新任务；读设置时暂不开放配置，失败在对话框内可见可重试。跨App方式记忆是本机项目P，参考只验证页间，不宣称其持久化实现。

skipExisting是每次Dialog的意图，不持久化；ReviewPanel根据已有结果设置initialSkipExisting。取消再开重算仍为关。预算、范围、候选数量仍每次默认，本片不臆测原站全部参数恢复。原有epoch/revision异步打开保护不变，无用户确认自动任务、无模式切换自动计算。

组件覆盖失败取消与重开、同一正在分析请求不停止/不变更棋谱、新App恢复、重算初值与显式缓存复用/强制重算、200%窄窗滚动；原生验证真实NNUE结果后重开配置及实际文件偏好恢复。更完整设置和原站高级候选算法仍待后续。
