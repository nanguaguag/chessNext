# ADR-018：版本化新手引导与只读教学

2026-11-02，F29/B08，当前实现，验收见TRACEABILITY。E01/E18证明参考4步/重放/跳过，持久规则和聚光控件并非本项目实现证据。

项目用Material3四步只读教学，避免教学自动修改正在阅读的棋谱、AI执方或本地内容。manual入口由离线帮助返回类型动作交给App协调，视图不访问仓库。production main启用首次提示，嵌入/测试宿主可以不自动弹；功能单独以启用模式验证，不依赖所有场景测试逐个点掉引导。

AppPreferences schema1新增可选guideVersion，旧文件0/当前1；完整DTO/equality/逐字段初始化合并，未来较大版本不降级。仅在读取成功后自动打开，用户完成或明确跳过才保存；中断不保存。设置读失败不借导览覆盖原件，写失败清晰提示并允许重试。指南标记不启动引擎/改变资源/恢复AI。

具体可观察验收、平台和限制见planning/ONBOARDING_SLICE与TRACEABILITY；本决策不宣称同站点聚光/实际操作闯关交互，若后续确认必须完整覆盖，另做真实控件定位引导增量。

慢读补充：自动提示只在根路由且无已打开模态时显示；让位用户已打开的帮助/设置，本次可手动重放，下次启动仍按未确认版本决定。已补延迟读取组件用例。
