# ADR-076：自建皮肤目录浏览界面

日期：2026-11-04
状态：接受

## 决策

访客皮肤目录通过M4-40的只读端口浏览。自建服务URL本机持久化，远程只接受HTTPS；允许localhost/loopback HTTP供本机部署使用。皮肤库提供在线排序、复用回车提交搜索、分页和刷新；列表与详情显示作者、点赞、描述、许可证和署名。断网、HTTP失败、协议错误和空目录有明确状态。

条目点击只打开详情，不会下载/接受许可/写入皮肤库。后续导入需用户确认许可和署名，校验包摘要与格式后再提交至本机目录。访客无需登录；账户和同步不在此范围。

## 验收

M4-41对应偏好 codec/迟到读取合并测试与在线列表、许可详情、离线状态 widget 测试。UI人工macOS检查受系统无法前置窗口限制，明确记录未验。
