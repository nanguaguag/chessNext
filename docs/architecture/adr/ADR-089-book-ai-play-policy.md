# ADR-089 AI单步的云库策略与本机回退

- 日期：2026-11-05
- 状态：接受（M4-57项目策略）
- 关联：F15、F22、F23、ADR-087、ADR-088、E71

## 决策

仅分析界面AI单步读取BookService设置；普通人机对弈和只读分析不请求云库。服务地址为空时完全离线。Opening策略为关闭/最佳/分差内随机；残局开关独立。离开开局库步数按已完成全回合计，本项目上限255（P）。残局分类暂按非将棋子≤8（P）；开局随机范围暂用最佳着法100cp内候选（P），按来源权重随机抽取。

服务候选先解析坐标并与当前规则引擎legalMoves核验；过期局面、无合法候选、miss、断网、拒绝/无效响应均不直接落子，改用既有本机引擎预算。界面明确告知走单步时会向配置服务发送当前局面和完整着法历史。分析引擎、当前分析结果与常规AI对弈均不受此设置影响。

## 未知与验收边界

E71验证了站点选项/残局开关/离库最小值1与初始10，但没有随机差值算法、残局识别、最大离库上界或实际查询/走棋结果。100cp/≤8子/全回合计数/255上限都是P，不写成站点事实。当前服务协议精确匹配FEN+完整历史，无近似位置命中；失败回退本机不会静默误称云库命中。真实外网部署与授权数据、设置变更全生命周期及macOS窗口可视验收仍需分别验证。
