# ADR-086 分析界面 AI 走棋预算设置

- 日期：2026-11-05
- 状态：接受（M4-54项目切片）
- 关联：F22、F23、E71、M4-54

## 背景

E71操作验证难度范围0–20、预设1/3/10秒和0不限时；不限时显示最大深度60。级别对应棋力、步时自定义上界及深度其它边界仍未知。ADR-004要求本地难度使用可解释的时间/节点预算，不假设Pikafish提供Skill Level。

## 决策

在独立分析界面AI走棋设置中持久化难度0–20、思考时间0或500–600000ms（500ms步进）和最大深度1–255（默认60）。0时不发送movetime，使用最大深度与节点预算；有限时间时使用movetime和节点预算。节点预算为`10000 × (difficulty + 1)`，值域/映射均为项目提案P，与参考站难度算法不等价。设置不改变连续人机对弈或常规分析配置。

通用schema1偏好新增字段均可选，旧值缺失回到20/1000/60；非法类型或越界值按既有严格读取/备份恢复策略处理。联网开局库、残局库与离库步数依赖单独的可替换BookService增量，本片不伪造在线结果。

## 验收

- 偏好在本机保存，旧配置可读，非法值拒绝。
- 设置只传给分析面板AI单步请求；时间0使用深度，不限时；难度作为有界节点预算。
- 编辑字号/窗口仍可滚动，搜索取消/过期保护继续有效。
- 真实参考站棋力算法、custom上限和在线云库结果保留U。
