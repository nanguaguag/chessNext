# ADR-093：显式自建版本检查与离线关于页

- 状态：已采纳（M4-61 客户端首片）
- 日期：2026-11-05
- 关联：F31、E70、E74、ADR-091、ADR-092

## 决策

- App 偏好提供可空的自建发布服务根地址。默认空值；空值时不联网，保存/读取仍兼容旧 schema 1 偏好。
- 仅用户点击“检查更新”时，由注入的 `ReleaseService` 访问 `GET /v1/releases/latest`。UI 不持有 HTTP 代码；无身份认证、棋谱、设备或浏览器标识字段。
- 公网端点只接受 HTTPS；HTTP 仅限 localhost/loopback。传输超时5秒，响应体最多2MiB，schema/历史最多100条并验证当前项一致、UTC发布日期、唯一身份与严格倒序。
- 分别展示新版本、当前已最新/本机版本高于清单、历史说明，以及不可达、服务拒绝和协议无效状态。服务端只发布元数据，不提供程序包、不下载或安装。
- 关于页提供Flutter许可入口。没有实现反馈/版权表单、设备信息收集或站点未确认的更新日志动作语义。

## 验收和限制

M4-61通过专项适配器与UI契约测试、根串行测试和Flutter分析后再提交；macOS只附加到既有进程热重启。用户自供URL、证书/网络异常及实际服务数据由服务运营者负责。版本常量仍由 `AppMetadata` 同步维护，真实构建注入待后续切片。F31及全站登录外差距继续开放。
