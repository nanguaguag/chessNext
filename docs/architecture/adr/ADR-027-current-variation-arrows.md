# ADR-027：本步变着双开关、父局面投影与有界编号

2026-11-02，E25访客自制树实测为边界依据。

全局showVariationArrows可选偏好默认true；局部BoardSession.showCurrentVariationArrows默认false，仅当前窗口视图，不写棋谱/草稿/偏好、不增内容或位置修订。根/新文档和打开App设置清局部，普通着法导航保留；改变局部不写全局，全局关时局部可开但不画，UI说明关闭位置。此显式状态机承接已观察到的返回边界，不推断站点内部页面实现。

CurrentMoveArrows为纯应用投影，基于当前节点父children，父Position记谱，稳定ID/原顺序编号与当前标识，按不可变树对象缓存。根空/单项有效；最多64（当前在首64外时以当前替换第64条），原编号不重排，完整列表不截断并明确提示。阈值是项目P，合法高机动局面覆盖超限测试。

绿色VariationArrowsPainter复用BoardArrowsPainter及共用Square映射/头部，增加只读数字徽号；画在棋子下、IgnorePointer/只读语义，不另开落子路径，列表仍经原引擎协调导航。主棋盘提供投影，编辑器不带旧树箭头。局部回调绑定epoch，过期文档不激活新窗口标记。

源站只验证编号1中心一次点击不切换，完整命中区域仍U；项目只读层为P。绘制上限/颜色/徽号位置不声称源站相同算法，F26其它标记和B22历史另做。
