# ADR-047：对面一方棋子朝向偏好

- 状态：已采纳（M4-11）
- 需求：F21 / B24
- 证据：E41

参考站设置描述为将上方一方棋子旋转180°。项目提供本机持久化布尔偏好，默认关闭；以棋盘视觉布局判定上方阵营，故棋盘翻转时旋转阵营随之变化。仅旋转棋子字形，棋子圆框、坐标、交互目标、末步/分析标记均保持其原方向。偏好通过BoardDisplayScope分发；主棋盘、局面编辑器和PNG/GIF快照一致。

旧schema1设置缺字段时默认false，设置异步读取晚于用户切换时不得覆盖该字段。源站皮肤库/编辑器不在本决策中，另由B24分片实现；不复制源站图像素材。

定向Widget测试覆盖默认、对面上下阵营和棋盘翻转；应用测试覆盖旧设置兼容、typed round-trip、非法值及延迟加载竞态。根测试/analyze及macOS启动证据登记于TRACEABILITY和SESSION_LOG。
