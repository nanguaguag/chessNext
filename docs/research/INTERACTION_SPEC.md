# 交互规格草案

观察项以证据索引为准；以下状态机和失败处理是项目提案 P，需要实现测试与补审计。

## 会话

SessionMode = browse / analyze / play / edit；红黑 AI 标志仅 play 可用。分析与自动落子互斥；变更模式先取消旧任务。新局/导入/切换棋谱在 dirty 时提供保存、放弃、取消；取消必须保留棋树和当前位置。自动草稿成功与显式保存状态分开。

编辑使用独立草稿，取消不污染棋谱，完成先验证局面及先手。规则校验失败显示具体棋子和原因，禁止发送非法局面到 native。翻转只改视图坐标，不改 FEN；红黑互换是领域操作，需要显式更新先手。

## 引擎与棋盘

idle→starting→ready→searching→stopping→ready；异常进入 failed，重启生成新 epoch。改变局面时取消旧搜索，旧 epoch/positionRevision 的 info 和 bestmove 不得影响新棋局。UCI 无请求ID，必须串行收尾再启动下一次搜索，不能仅给消息贴新 ID。

info 显示分数视角、cp/mate 类型、bound、PV 编号、深度和采样时间；mate 不冒充普通分值。对弈立即出招请求停止并消费本次 bestmove；取消搜索丢弃结果。无合法着法/终局禁用立即出招。变招在候选耗尽时明确提示，不循环卡住。

## 导入导出

空导入禁用（已观察）；解析在隔离任务执行，文件大小/深度/数量限额可配置。先预览再替换，不因部分成功覆盖草稿。格式损失（不支持注释或变着）必须说明。图片识别结果进入可编辑局面并允许取消；相机拒绝提供本地图片路径。

## 在线与恢复

在线端口返回 success / empty / unavailable / unauthorized / rateLimited / invalidData，区分无结果与失败。离线不弹循环登录；保留本地棋谱和引擎操作。后台/锁屏停止分析，恢复由用户选择，防止热耗电。崩溃恢复草稿，不自动继续落子。

## 待补实测

真实站点的终局、互斥、脏数据弹窗、长将长捉裁决、变招耗尽及恢复行为尚未验证。本草案不冒充其精确行为。

## M2-08项目文字交换（P→本地实现）

先解析完整输入才创建新文档；错误提示保留原文供修正；空输入禁用导入。未保存文档在解析成功后提示保存/替换/取消，不为无效输入打扰用户。Clipboard异步返回不覆盖读取期间已修改的文字；超限/空值/拒绝访问分别提示。导出弹窗捕获打开时的不可变棋树快照，FEN与当前路径格式明确说明损失；复制只有写入成功后显示成功。URL暂不联网抓取。

M2-09：棋谱路径与继续变着显示中文纵线，坐标放在Tooltip供排查；导出格式增加中文棋谱选项，仍只含根FEN与当前路径。导入接受着法前的数字编号，繁体与半/全角数字等价；不静默忽略注释或未知格式。

M2-11项目读谱：列表显示所选线路全部过去/未来着，导航不删棋谱；从变着回到祖先保留该线路，首尾/前后沿它移动，选别的变着再换线。点击/普通读谱导航暂停自动对弈、保留当前分析跟随；“悔棋”是独立对弈操作。导航不增加内容dirty，自动草稿仍保留读谱元数据。选中自动可见，用户自行滚动时不因分析info强制跳回。

M2-12：本步变着基于父局面列同级节点，下一着基于当前局面列子节点；二者均有界滚动、选中与主线标识。提升主线不切当前节点，已是主线禁用且领域/会话无额外dirty。删除先明确确认具体着法及后续/注释，随后绑定epoch+内容revision并停AI；等停止期间若有新操作则不删除。取消不改变棋谱。

M3-08曲线为红方原始评分可视化，数值±10兵仅绘图封顶，文字显示实际值。杀棋三角、上下界方向、缺失断线；mate0不伪造0兵值。点击/方向键/Home/End/语义增减/滑块跳转均使用稳定节点ID并经引擎协调器，过期结果不可导航；切到未分析分支显示缺失，不借用其他线路分数。

E21字号：网站设置实时生效，手动三档100/115/130自动退出follow；开启follow后退出回标准100，不保留旧手动值。项目新增独立字号对话框实时应用/本机记忆/失败保留当前效果并可重试，普通设置表单保存需保留此字段。系统模式使用原TextScaler不二次相乘，显式手动模式覆盖系统缩放；不改棋谱或引擎请求。

M3-20本地坐标：棋盘显示即时开关，偏好不写棋谱；主棋盘/编辑器共用Scope，坐标上下独立边框，红方九至一/黑方1至9依逻辑file与视图翻转镜像映射。命中始终按内部格距和Square，不缓存改变显示前的屏幕坐标；标签本身只读，不落子。此为P，站点E22只证数字显隐与导航记忆。

M3-21尺寸：10–200%/步5即时保存，重置只改100%，90交点点击/语义与坐标/箭头不缩放；实际棋子及拖动反馈同一face变换，较大值重叠在内部棋盘边缘裁切。源站E23只证显示效果，项目不让重叠改变命中是P。
