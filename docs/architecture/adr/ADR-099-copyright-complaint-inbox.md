# ADR-099：版权投诉表单与隔离自建收件

- 状态：接受（M4-67 项目切片）
- 日期：2026-11-05
- 需求：F31 / E74、E81

## 决策

在已配置的自建发布根地址上增加访客版权投诉入口。投诉字段包括投诉人、邮箱、作品/权利类型、权属说明、涉及内容定位和可选补充文字。必填边界、字段长度、最简邮箱格式校验为项目契约P。用户必须勾选真实性声明，先看完整目标与字段预览，再明确确认提交；预览和取消不产生请求。公网仅HTTPS，HTTP仅loopback。

客户端通过`CopyrightComplaintService`发送到`POST /v1/copyright/complaints`，只提交表单文字。附件尚不可用，不承诺投诉处理或回复。网络失败/服务拒绝/无效确认有区分，不自动重试。关于页服务地址为空时入口禁用且保持离线。

服务端仅在显式配置`CHESSNEXT_COPYRIGHT_ROOT`时开放路由，严格校验schema1字段/长度，最多16KiB请求、1,000条；单独的私有目录存储，不提供公开读取、列举、删除、邮件转发、附件处理或自动清理。部署者须先设置服务账号私有目录、访问与删除/保留策略。Nginx样例关闭access log并将该路径限制为每IP每分钟2次；托管网络仍可观察来源IP。投诉目录与普通反馈目录分开以便更严格授权与保留。

## 验收与剩余

客户端仅预览/显式提交测试、HTTPS策略/请求payload测试、服务端拒绝未知字段和无公开读取测试、root门槛及既有macOS实例同步记录于TRACEABILITY。屏幕锁定时不宣称人工视觉验收。真实个人投诉、附件上传、生产部署/运营收件、公开邮箱/讨论群外链仍未交付；F31开放。
