# ADR-103：棋盘几何拖动期间保留乐观预览

- 状态：接受（M4-71 / F21,B24）
- 日期：2026-11-05
- 需求：B24 / ADR-090、ADR-102

## 决策

`BoardGeometryEditor`在拖动时自行维护当前指针对应的预览。父级控制器开始异步保存时会先通知`loading`变化，传入值仍可能是上一次已持久化几何；不能把这个旧值误当成外部编辑并覆盖拖动状态。因此，只有收到与旧属性不同的新几何且当前没有拖动时，才从父级同步；正在拖动时保持本地乐观预览，保存完成后由新属性收敛。键盘/读屏单步与主设置数值控件继续由父级偏好状态更新。

这是针对项目状态同步时序的P，既不改变归一化值映射，也不说明参考站拖动精度或边距公式。

## 验收与剩余

组件测试在每次值变化后强制父级用旧已保存值重建，拖动结束检查最新值和把手位置没有跳回。其它验证及限制见`docs/planning/TRACEABILITY.md`。参考站完整几何、保存/应用/reload语义仍U。
