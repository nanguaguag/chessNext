# ADR-096：本机界面色调

- 状态：接受（M4-64项目切片）
- 日期：2026-11-05
- 需求：F27 / E78

## 背景

E78观察参考显示页有晴蓝、青玉、枫木、檀木、墨五个色调选项，并操作验证青玉/晴蓝单选状态。本次没有验证每种色调具体影响范围、色值、夜间棋盘或持久化。chessNext此前用固定绿色Material 3 seed。

## 决策

为五个命名色调提供本机`DisplayTone`偏好，跨浅/深主题只改变Material 3 `colorSchemeSeed`，其它组件使用语义色彩角色。色值分别为项目提案（P），不复制或推断源站像素值。默认晴蓝按E78当前观察与源站默认选项对齐；旧schema1偏好缺字段安全解析为晴蓝。此默认会令未显式保存色调的既有安装从旧绿色seed切换为晴蓝，用户可改选五种之一。

本切片不改变棋盘木色、棋子/标记、主题模式，也不添加“深色模式用夜间棋盘”；其逻辑/作用对象尚未审计，只有默认皮肤条件的文案证据。色调效果在Material 3语义主题中应用，不承诺与源站所有页面视觉完全一致。

## 验收

- 五选项在设置可访问，切换需点击“应用设置”后保存，取消不提交。
- system/light/dark模式均以同一tone生成主题seed；不影响棋盘皮肤、引擎及棋谱。
- schema1读写、旧字段缺省、异步设置读取与用户新选择合并正确。
- 设置控制器与Widget专项、根`flutter test --concurrency=1`、`flutter analyze --no-pub`通过；macOS复用既有实例运行。

## 未解决

源站五色值和跨页面作用、跨重启持久性、夜间棋盘条件/算法及语言覆盖仍U。F27未关闭。
