# ADR-008 桌面失焦与真正隐藏分别处理

状态：接受，2026-11-02；关联B20、F02/F03。本切片修正设置/原生流程验证中暴露的生命周期边界。

依据[Flutter AppLifecycleState官方定义](https://api.flutter.dev/flutter/dart-ui/AppLifecycleState.html)，inactive在桌面表示有可见窗口但无输入焦点；hidden才是全部视图隐藏。桌面macOS/Windows/Linux在inactive继续已启动的搜索；hidden/paused/detached取消搜索，恢复可见后不自动恢复AI。Android/iOS仍在inactive先取消，保持移动设备中断时的保守行为。

草稿和设置在所有非resumed状态均尝试flush，不受引擎暂停策略影响。正常退出等待本地写入；强制终止仍无通知保证。

组件测试分别模拟移动inactive取消、桌面inactive继续和hidden取消；恢复测试遵守hidden→inactive→resumed状态序列，隐藏时不以尚未重绘的文字判断状态。原生测试记录事件trace，不能把没有权限置前的桌面窗口假定成始终resumed。Windows/Linux和真实移动设备行为仍待各平台实测。
