# ADR-064：本机棋步移动动画

状态：接受（2026-11-04）

## 背景

E36只确认源站提供“关/快/标准/慢”动画速度选项；棋子移动是否动画、各档时长映射仍未知。项目已有AnimationSpeed项目映射（ADR-042），但实际棋子只在离散格点切换。

## 决策

- 主棋盘在显示的棋步身份变化后，将刚走棋子从Move.from过渡到Move.to；时长沿用AnimationSpeed（关=0、快=300ms、标准=600ms、慢=1200ms，均为项目P）。
- 过渡时暂时隐藏落点格的棋子视觉，忽略输入且不重复读屏语义；棋谱、规则、引擎和逻辑交点即时提交，不等待动画。
- 系统减少动态效果优先静态显示。离开主棋盘的局面编辑、分析预览、PNG/GIF快照不播放该动效。
- 新棋步打断并替代旧动效；无可见目标棋子、动画关闭或Reduce Motion时直接显示最终局面。

## 后果

动画速度设置现在控制末步标记、落点图片旋转和主棋盘棋子移动。源站具体动效范围/速度映射仍U；本地行为不可据此宣称参考站完全一致。
