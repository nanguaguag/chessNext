# ADR-113：自建大师谱授权整局详情与只读复盘

- 状态：接受（M4-83 / F15,F20）
- 日期：2026-11-05

## 背景

M4-80/81只查询位置索引元数据，尚不能打开整局。仓库不附带第三方棋谱数据。自建服务只有在运营者提供并有权展示整局的情况下才可返回PGN。

## 决策

- 索引记录可选包含最多64,000 UTF-8字节的`pgn`；既有不带该字段的数据仍有效。
- 位置查询继续只返回元数据和`hasRecord`，不随列表预取PGN。
- 用户明确打开一条有棋谱的记录后，客户端按稳定record ID请求`GET /v1/master-games/records/<id>`。详情响应同时包含数据集ID、许可证、署名和PGN；无整局或未知ID返回404。
- Flutter HTTP适配器校验ID、响应schema/大小、数据来源以及返回ID/FEN/着法历史。应用控制器还核对当前查询局面和完整历史、PGN主线中存在对应根局面到目标局面的路径及可用棋手/赛事标签；若查询局面、文档或结果集合已变化，丢弃迟到详情。
- 预览捕获不可变PGN树，只读显示主线棋盘和着法导航，不写入主棋谱、不驱动引擎。显示数据集许可和署名。
- 真实收录/展示授权由部署运营者负责；项目不复制或捆绑网站棋谱。参考站整局点击、分页和复盘细节仍未知，本实现是项目提案，不声称精确复刻。

## 失败边界

无整局、网络不可达、HTTP拒绝、超限/畸形PGN与来源不匹配均明确失败；不显示部分或未经校验的棋谱，不更改当前棋局。在线日志配置关闭查询和整局详情路径访问日志。

## 验证

实现/验证证据记录在`docs/planning/TRACEABILITY.md`的M4-83条目；真实部署数据授权及macOS运行时/人工视图验收未验证。
