# ADR-091：离线本机关于与依赖许可列表

- 状态：已采纳（M4-59 F31首片；远端功能待后续）
- 日期：2026-11-05
- 关联：F31、E70、E74

## 决策

- 应用设置增加“关于与开源许可”入口，显示应用名、当前pubspec版本`0.1.0+1`和离线优先说明。
- 调用Flutter本机`showAboutDialog`及`LicenseRegistry`，为依赖包提供随应用构建的本地许可页；浏览不访问网络、不更改设置。
- 明确本版本尚未配置更新和反馈服务，不后台检查更新或发送设备信息。不得提供虚构的检查结果、日志或联系渠道。
- 后续更新元数据、反馈收件与版权处理作为独立在线功能，须使用用户可替换自建后端并在请求前披露目的地/字段；E74观察到的设备信息字段不默认启用。提交动作和数据模型另行ADR及用户确认体验。

## 验收

设置入口打开AboutDialog，版本和服务状态可读；依赖许可导航可达；浏览不触碰偏好存储；根测试、analyze和既有macOS实例同步/热重启通过。

## 边界

此片不是完整的站点About页对齐：真实build id、更新检查、更新日志、反馈/投诉流程、外部交流链接与后台仍未实现/验证，F31保持开放。手写版本必须与pubspec同步；后续宜从构建注入真实版本信息。
