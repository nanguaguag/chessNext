# ADR-105：棋盘皮肤保存与应用分开操作

- 状态：接受（M4-73 / F21,B24）
- 日期：2026-11-05
- 需求：F21,B24 / E59–E61、E67

## 证据

E67在访客新建页分别操作：保存几何后编辑页仍打开且当前设置保持“默认棋盘”；选择器里能看到“我的棋盘”，再点“使用这套”才切换当前皮肤。已保存的皮肤重新编辑后再次保存，也不会自动应用。会话内重新进入可读回数值；reload/重启仍U。

## 决策

本机皮肤库同时提供“仅保存”和“新建并使用”。两者均基于当前皮肤复制棋盘底色、格网、几何与自定义图层并创建唯一项目ID；仅保存不改变当前选中ID/棋盘呈现，新建并使用在定义成功写入后选择新皮肤。已保存未选中的皮肤可由列表“使用”独立应用。导入保留原有显式确认及导入后应用策略。

此状态边界对应已操作验证的源站行为；皮肤数据格式、自动dirty策略和跨刷新/重启持久性仍不假定等同。

## 验收与剩余

Widget测试分别验证仅保存保持当前内置皮肤并增加本机定义，以及新建并使用当前ID变化。根门槛与macOS复用结果见TRACEABILITY。图片与几何重载、站点reload持久性仍按各自接口/证据追踪。
