# ADR-100：问题反馈的显式图片附件

- 状态：接受（M4-68 / F31 项目切片）
- 日期：2026-11-05
- 需求：F31 / E74、E81

## 决策

问题/建议表单可由用户通过平台文件选择器显式选取最多3张PNG/JPEG图片；单张≤256KiB、总字节≤512KiB。拒绝不安全文件名、扩展名不支持、签名与声明MIME不符、读取异常和超界文件。选择后可预览/移除；完整反馈预览列出附件名、MIME和大小，只有用户再次确认后才随文字字段提交。不会自动截屏、读取棋谱或扫描设备文件。限值和JSON base64协议为项目设计P；源站附件接收、文件格式及字段行为仅部分观察、未提交验证。

反馈HTTP请求最大编码体为768KiB；自建服务仅接受严格附件结构，并将base64内容写入与普通反馈相同的私有有界收件记录，不开放下载或读取接口。Nginx反馈路由请求体上限设为1MiB。服务端继续最多5,000条；反馈文本/投诉仍按各自16KiB限制。运营者必须按其私有反馈保留政策处理附件。

## 验收与剩余

选择器、预览确认、HTTP协议、服务端PNG附件存储和非法/越界输入均由契约测试覆盖。Flutter根测试、analyze、服务端测试/analyze/exe编译、复用现有macOS实例attach/hot restart记录在TRACEABILITY。真实生产部署、运营者访问/删除/保留流程、投诉表单附件、外部交流入口仍未完成；F31继续开放。
