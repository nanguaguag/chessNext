# ADR-054：棋盘皮肤几何校准

- 状态：提案（P），待作为独立功能切片实现与验证
- 日期：2026-11-04
- 关联：F21、B24、E44–E47

## 证据边界

E44观察到左上/右下格点、左/上/右/下边距stepper和棋子缩放控件；E46重复左边距三次，显示左33→34.5、右465→465.06。E45确认切换落点旋转控件，但无自定义图片时效果未知。上述是源站观察/操作结果，不足以确定单位、值域、联动公式、缩放对象或旋转时序。不得将这些数字或行为冒充源站规格。

## 项目模型提案

- 新增纯Dart `BoardSkinGeometry` 值对象，存储相对于棋盘画布的归一化内部格网矩形（left/top/right/bottom），而非窗口像素或参考站stepper数值；旧/缺失配置映射到当前标准9×10格点。
- 内部格网由9列、10行交点定义。一个几何映射函数把逻辑`Square`转换为画布坐标；反向命中通过同一映射取最近交点。绘制格线、棋子、末步标记、选中框、分析箭头、局势徽标、坐标轨和拖放命中必须共享此映射。
- 几何编辑在预览棋盘上以左上/右下交点拖柄调整范围，并提供四边小步进控制。项目存储归一化值，输入与拖柄连续，控制值本地定义；不复制源站33/465等数值。边界约束保证左右/上下顺序、至少保留完整的8×9间距，且所有映射点位于画布可见区域；拒绝非法值并保留上次有效值。
- 横纵交点间距分别按对应端点线性插值。允许不同X/Y比例以适配非标准背景；命中使用实际布局尺寸转换，不使用缓存的旧屏幕偏移。flipped/mirrored只改变逻辑到视觉坐标的映射，不改变几何配置。
- 皮肤专属棋子缩放作为独立整数百分比，初值100%、范围80–120%、步进1%，与现有全局棋子10–200%比例相乘；仅缩放棋子面容，交点命中半径与逻辑格不变。这是项目P，不推定E44控件语义或源站范围。
- `BoardImageSnapshot`、`BoardGifSnapshot`冻结同一几何与皮肤棋子缩放，导出不得读取预览期间更新的偏好。主盘、编辑器、图片/GIF预览共用一个呈现端口；领域规则模块不依赖Flutter。
- 几何草稿须有明确“保存/应用/取消”边界：取消不写本机库或当前选择；保存只更新所选本机皮肤；应用选择该皮肤；失败保留原几何并呈现可恢复错误。此为项目P，网页这些入口成功状态仍U。

## 旋转另行处理

落点标记图旋转保持单独切片：E45只验证开关状态从0到1。项目提案为终点图片在新落子时围绕格点单周旋转后静止，速度沿用当前最后一步动画偏好并服从系统减少动画；历史导航是否播放、连续重渲染不重复动画需另行定义与测试。不得把该提案写成源站行为。

## 验收条件

1. 归一化几何默认/序列化/旧值迁移/坏值拒绝有纯Dart测试。
2. 拖柄与步进器保持边界不变量，恢复默认及取消草稿有应用层测试。
3. 正反/镜像下绘制、所有标记与反向命中经同一映射；访问性描述仍指向逻辑坐标。
4. PNG/GIF快照冻结几何和皮肤棋子缩放；在预览中改变设置不改已打开快照。
5. macOS完成编辑器、保存/应用/取消的实际运行检查；主盘及编辑器可视验证通过后才关闭该切片。

## 未知

源站格点/边距/缩放端点、缩放对象、四边联动关系、持久化模型、保存/使用/导出含义及落点图片旋转时机均保持U。需要新证据时按可撤销草稿路径操作并记录截图或状态。
