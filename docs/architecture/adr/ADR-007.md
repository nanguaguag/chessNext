# ADR-007 本机偏好设置与资源能力约束

状态：接受首个macOS实现，2026-11-02；关联B08、F22/F24/F25/F27部分。

AppPreferences为无Flutter依赖的版本化值对象（schema1），包含主题、线程、Hash、MultiPV和AI用时；明确不存AI角色、当前搜索或账号。PreferencesRepository独立端口；生产用ApplicationSupport/chessnext-settings，预览/测试显式内存适配器。校验类型、枚举、范围和未来schema，拒绝非法配置。

读取失败使用安全默认值并提示，未经用户修改/明确重试，不在后台自动用默认值覆盖坏文件；备份可恢复，重写损坏原件前归档。串行保存保留最新配置，失败仅影响持久化，当前设置仍生效。初始化读取与用户操作逐字段合并，flush等待初始化完成。显式保存棋谱及自动草稿与设置文件互相独立。

引擎设置与AI用时一次提交至EngineSessionController；切换主题不重启搜索。参数受应用上限（1024线程/1024MB/256PV）、设备线程数及握手能力约束；未握手只应用策略上限，握手后再次钳制并持久化有效值，不宣称引擎已支持未知能力。未知选项仍由EngineGateway拒绝。跨设备/引擎升级后优先安全运行，不自动开启AI。

沿用临时文件flush+同目录rename和备份，非跨进程事务，不声称断电目录fsync或Windows替换语义已验收。后续语言/字号/外观/声音用明确schema迁移扩展，不能预先持久化未实现选项。
