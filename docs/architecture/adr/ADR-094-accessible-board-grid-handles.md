# ADR-094：可访问的棋盘格点校准控制

- 状态：已采纳（M4-62 项目增量）
- 日期：2026-11-05
- 关联：F21、B24、M4-58、E76、E77、ADR-090

## 决策

- 本机校准器的左上与右下格点把手均可聚焦，语义提供标签、四条边的百分比值和操作提示。
- 聚焦后方向键每次按项目模型1个百分点分别调整水平或垂直坐标；读屏自定义动作提供左/右/上/下各1个百分点操作。控件边界和最小跨度继续遵守 `BoardSkinGeometry`，不修改逻辑棋盘/落子。
- 拖动以原始pointer-down坐标和拖动开始时几何为基准，抵消Flutter pan识别阈值在首个`DragUpdateDetails.delta`中遗漏的位移。每帧按总位移计算，避免累计误差。
- 方向键步长和ARIA值属于项目设计，不移植站点0.5及其未知像素/坐标映射。参考站E65一次ArrowDown无变化不证明其完整键盘边界。

## 验收

组件测试覆盖鼠标/触控拖动总位移、方向键、读屏语义动作存在、最小跨度边界及异常；根目录串行测试和分析为提交门槛。macOS使用既有进程热重启，不启动第二个App。
