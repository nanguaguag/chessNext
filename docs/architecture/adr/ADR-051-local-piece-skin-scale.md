# ADR-051：本机棋子皮肤独立大小

- 状态：已采纳（M4-15）
- 需求：F21 / B24
- 证据：E43（滑杆部分观察；值域最小端点和保存语义仍未知）

本机圆章、方章各自持有`roundSealPieceScalePercent`/`squareInkPieceScalePercent`，旧schema1数据缺省100%。值域80–120、步进1是项目P，避免将源站滑杆观察到的70上限和未确认的另一端点直接当产品规格。设置即时持久化；切换预设显示对应值。有效棋子面容缩放为全局棋子百分比×皮肤百分比，格子尺寸、逻辑坐标和命中区域不随之变化。

`BoardDisplayScope`只读传递当前皮肤倍率；图片/GIF快照保存独立皮肤百分比，以便导出呈现打开时的预设。不改变棋谱、局面、引擎搜索或位置标记。后续完整皮肤可将该参数迁移至皮肤元数据/配置仓库，但在迁移前维持稳定偏好键和默认兼容。
