# ADR-044：本机系统语音朗读着法

- 状态：已采纳（2026-11-03）
- 关联：F28、B23、M4-08、E36/E39

## 决策

棋步提交经应用层 `MoveSpeechPort` 发送标准中文着法；它独立于所有音效偏好。界面开关默认关闭并持久化。生产适配器使用 flutter_tts 4.2.5 系统 TTS，只选择已安装的中文语音；Android 排除 `network_required` 语音，不发起在线合成。没有可用中文语音、平台插件不支持或系统调用失败时静默降级，不能阻塞着法。

系统插件声明支持 Android/iOS/macOS/Web/Windows，未声明Linux；生产适配器明确对Linux与Web关闭朗读。本项目不自动下载或安装语音包，也不保证OS语音模型已经离线安装。将来的Linux实现需单独验证本机服务后替换端口。

连续着法由适配器串行处理；关闭开关不回滚或取消着法。位置历史导航与落子一样是位置修订，当前会触发朗读；这一行为尚待源站事件实测，属于项目策略。

## 验收

纯Dart fake确认中文着法、独立偏好、默认关闭、异常隔离；macOS集成测试实际调用插件查询已安装中文voice并尝试朗读。集成测试不证明每台设备都安装中文离线语音，也不代替人工听感和其它系统测试。
