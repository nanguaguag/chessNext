# 离线范围基线 / 2026-11-01

本文件为新版主线，保留原始全站矩阵用于远期对标。登录后功能不做；不为审计注册账号。离线产品可以提供本地棋谱管理及本地错题收藏，不依赖网站账号，也不表示已确认其登录后行为。

本表定义离线优先的交付顺序，不从总范围删除其他在线能力。用户已授权后续继续实现公开云目录等在线功能，使用自建、可替换后端并提供部署方案；登录后功能仍排除。在线请求须由应用端口访问，明确断网/超时/缓存状态，不能以本地假数据伪装在线成功。

| 需求 | 本地交付定义 | 阶段 |
|---|---|---|
| F01,F04–F06 | 规则、走棋、终局、导航、悔棋、局面编辑、视图变换、取消与脏数据保护 | M2 |
| F07,F08,F10,F12,F13,F18 | FEN/文本先行；本地文件导入、棋树分支注释、本地保存/检索/最近阅读；逐格式扩展 | M2/M4 |
| F02,F03,F22–F25 | 原生NNUE、分析、MultiPV、执红/黑/双AI、催招、变招、资源参数、离线难度预算 | M3 |
| F14,F32 | 单步局势、整谱异步复盘、失误列表与持久化；阈值与规则单独校准 | M3 |
| F11,F12 | 本地图片/GIF/文字/文件导出、系统分享本地文件；远端链接生成延期 | M4 |
| F19–F29,F31 | M3设计、布局、棋盘外观、字号、语言、声音动画、引导、关于/第三方许可 | M3/M4 |
| F16,F17,F30 | 登录后账号棋谱/云同步延期；访客公开内容与本地功能另行审计 | 延期/本地扩展 |
| F09,F15 | 云库和服务端识图先延后实现；按总范围采用自建可替换服务，不以“离线优先”将在线能力移出范围 | 后续在线 |
| F21/B24在线皮肤目录 | 公开只读服务端已有首片；Flutter客户端配置/断网缓存/平台验收仍待实现 | M4 |

“所有离线功能”不包括模仿联网云库的按钮或假数据。规则不一致、格式有损、未授权NNUE、未运行平台都必须透明标注。完整五平台支持需 M5 实机签核，不因本机成功即宣称完成。
