# ADR-053：本机棋盘皮肤图片图层

- 状态：已采纳（M4-17）
- 日期：2026-11-04
- 关联：F21、B24、E44

## 背景

E44在参考站棋盘皮肤编辑器中观察到棋盘、起点、落点、选中框四种图片槽，以及棋盘格点、坐标、缩放和落点标记旋转入口。图像替换/保存/应用的网页成功结果未操作，精确几何及旋转规则未知。项目先交付离线可验证的逐槽图片覆盖，不把它描述为完整复刻网页编辑器。

## 决策

- 每种本机 `BoardSkin` 独立保存四种 PNG/JPEG 槽：背景、起点、落点、选中框。
- 重用已有 `PieceImagePicker` 和 `PieceImageValidator` 的有界图像选择/校验契约；各槽Material 3替换、预览和恢复默认。
- 持久化使用独立 `BoardSkinImageRepository`，manifest限制文件名/扩展名并拒绝受控目录中的符号链接；通过暂存目录和rename替换，损坏素材加载时跳过。
- 主盘和局面编辑共用 `BoardDisplayScope` 的只读图层。自定义起点/落点图分别替代对应默认末步标记；背景位于网格下方，选中框位于棋盘内容上方。
- PNG/GIF生成使用打开时冻结的图片字节，预览期间偏好变化不改变快照。
- 旋转开关和格点/四边几何编辑尚未实现，须另立增量并继续以P/U标记。

## 结果

本机棋盘图片可离线替换并用于主棋盘、局面编辑、PNG及GIF。当前不提供ZIP/多图/文件夹导入、棋盘布局几何编辑、皮肤库管理或在线目录；不改变棋谱、规则或命中区域。图层语义/透明内容由用户图像决定，项目不复制参考站素材。
