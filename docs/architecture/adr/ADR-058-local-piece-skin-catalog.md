# ADR-058：本机棋子皮肤目录

状态：接受（2026-11-04）

## 背景

E41/E42/E48观察到皮肤清单、新建、导入、ZIP与文件夹入口；E48说明层声明一个压缩包可含多套并允许选择导入项，也声明只保存在本机。没有完成文件选择或导入，格式、目录、冲突和成功语义仍为U。现有`PieceSkin`只有两个内置预设，不能表达多套独立用户皮肤。

## 决策

- 内置`PieceSkin`继续代表基础视觉风格；用户皮肤以稳定自定义ID引用一个内置基础风格。
- 用户皮肤在本机皮肤目录持久化名称/ID/基础风格；用户图片按自定义ID隔离存储。新建时复制当前皮肤的图片覆盖，保留扩展名与原字节。
- 设置内可选择用户皮肤，并新建（从当前复制）、重命名、删除。内置预设不可删除/重命名；删除当前用户皮肤先切回其基础内置预设。
- 目录限制64套、清单64 KiB、名称最多32 Unicode码点、ID使用受限字符集（项目边界P）。本机清单拒绝重复ID/名称和符号链接清单。
- UI只调用应用控制器；文件访问通过仓库端口。没有服务端请求或账号依赖。

## 未包含与待办

本片自定义皮肤沿用基础预设的大小、位置、阴影和棋盘关联参数，尚未做到逐用户皮肤独立编辑；没有列表搜索/排序、导出、ZIP/文件夹导入或在线目录。参考站各项可用性、范围与操作成功仍U。后续B24继续拆分，并保留自建可替换在线服务的总范围。

## 验收

目录往返/异常数据、创建/重命名/选择/删除、图片隔离与复制、设置持久化；根`flutter test`、`flutter analyze`、macOS Debug运行。实现结果与命令记录在TRACEABILITY。
