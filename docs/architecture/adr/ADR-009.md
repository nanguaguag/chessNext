# ADR-009 搜索token与文档上下文分离

状态：接受当前桌面适配器，2026-11-02；关联B14/B18。

搜索token用于丢弃迟到结果；新增gameId只用于文档epoch。资源所有者EngineSessionController在分析与AI请求中传session.epoch。UciEngine记忆(gameId,规范根FEN)及已确认资源参数：同文档导航/重新搜索保留TT，只在资源变化时setoption、首次/文档变化时ucinewgame，随后isready/readyok确认；旧搜索仍先stop/bestmove，不重入go。

不以报告缓存替代引擎完整历史；每次position仍携带全部路径。新适配器/进程无缓存，未知/非法参数先拒绝。应用规则profile未来变化必须扩展上下文身份，不能只改UI文本。单窗口调用约定保持不变，不声称跨实例共享TT。

性能证据与边界见engine/RESOURCE_REUSE.md；不改上游，不用暖缓存样本承诺通用速度或棋力。
