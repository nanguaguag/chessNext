# ADR-010 所选读谱线路与导航元数据

状态：接受项目设计，2026-11-02；关联F01/F13、B16/B18。E12确认当前列表可含游标之后的着法；变着回退保持策略为项目设计，仍须源站分支审计补证。

GameTree保留不可变lineAnchorId读谱锚点。currentLine为根至锚点路径及其后主线，游标始终在该线路中。回退/跳至祖先保持已选变着，选择别的分支切换线路；删除锚点或主线重排致上下文不兼容时回到当前游标为锚点。first/forward/last沿当前线路，不能在回退后静默跳回另一主线。

schema1新增可选lineAnchor字段，仅为导航元数据，不改变规则或节点。旧快照缺失时使用cursor，可正常打开；新字段类型、节点存在性、线路包含游标均验证，坏数据不静默修复。内容修订不因导航增加；同步内容hash/分析缓存不能把cursor/lineAnchor当棋谱着法变更，未来最近阅读应按读谱状态处理。

UI MoveList有界虚拟渲染、选中样式、当前着自动滚动、完整中文语义/坐标Tooltip。千着测试只验证挂载行数有界，不声称真实帧率达到特定数值。UI只发节点意图，协调器暂停AI并等待stop屏障；迟到切换不能覆盖后来的操作。普通读谱“上一着”一步，显式对弈“悔棋”仍回到人类回合。活动分析可跟随新局面。
