# ADR-073：棋盘布局预设

- 状态：已接受（项目行为）；源站尺寸算法仍未知
- 需求：F27、B25；证据：E57
- 日期：2026-11-04

E57在1280×720访客桌面观察到“棋盘靠左”和“棋盘居中”会改变主工作区列顺序。居中态为左侧着法、中央棋盘、右侧引擎/云库，并观察到22/70/55/55分隔值；靠左态把棋盘与着法置左、分析/云库置右，AX棋盘宽39且左栏分隔条消失。只验证此视口，不代表完整断点或宽度范围。

本机将预设保存为`AppPreferences.boardLayoutPreset`，缺失字段兼容居中。设置对话框应用时写本机偏好。`centered`继续使用M4-37工作区；`boardOnLeft`在≥1280dp显示棋盘、记录/操作和右侧面板，棋盘宽度采用项目范围508–556dp，记录区至少220dp、右区至少220dp；一个可拖动/键盘可调/Slider语义分隔条控制棋盘宽度，重置回项目默认。上述本机几何全部为P，不声称对应站点39或其内部算法。

偏好字段走既有schema1可选字段和逐字段异步读取合并。布局状态在工作区实例中，切回预设可重建；窄窗沿用原自适应工作区。旧偏好解码、异步读取期间用户编辑和控件布局有回归覆盖。根测试、分析与macOS build/sync通过；macOS锁屏导致应用无法置前，真实窗口视觉和人工拖动仍待验。语言功能及F27其他范围不因本ADR关闭。
