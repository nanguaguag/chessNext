# ADR-055：自定义落点图片旋转

- 状态：已采纳（M4-19），项目行为P；参考站真实动效仍U
- 日期：2026-11-04
- 关联：F21、B24、E45、ADR-054

## 证据边界

E45只验证棋盘皮肤编辑器中的“落点标记旋转”开关由0切换到1；当时没有自定义落点图片，实际画面与时序无法观察。以下行为均为本机项目提案，不写作参考站复刻。

## 决策

- 偏好按BoardSkin保存，与该皮肤的自定义落点图片一起作用；关闭开关或无自定义落点图片时沿用默认最后一步标记，不增加动画。
- 棋谱当前位置出现不同的末步或身份时，自定义落点图绕对应交点线性旋转一整周后静止。首次挂载已存在的末步保持静止；同一身份重建不重播。导航到不同节点会按新身份播放一次。
- 动画时长复用全局AnimationSpeed（关/快/标准/慢）；系统Reduce Motion优先并立即静止。动画不改变布局、命中、棋谱、引擎或起点图。
- PNG/GIF快照沿用既有静态捕获，不导出进行中的旋转动画；后续如要动画GIF，另立需求。

## 验收与边界

模型测试覆盖新旧偏好序列化；Widget测试覆盖只旋转落点图、身份变化触发、同身份重建不触发、动画速度和Reduce Motion。仍需macOS运行与可视检查；源站是否同样按新着法旋转、动画时长及导航语义均U。
