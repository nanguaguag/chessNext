# ADR-087 自建只读开局/残局云库服务

- 日期：2026-11-05
- 状态：接受（M4-55服务端首片）
- 关联：F15、F22、F23、E71

## 决策

在现有可自建服务增加可选`POST /v1/book/query`。运营者通过`CHESSNEXT_BOOK_ROOT`发布schema1 `book.json`，服务启动时装载到内存，只接受精确的库种类、FEN和完整ICCS/UCI历史查询；返回命中候选、miss或有界协议错误。合法着法检查与选择策略归客户端，引擎回退由应用决定。服务不自带、不下载、不录入任何第三方棋库，不提供用户上传或账号。

manifest必须声明dataset ID、license和attribution；每个候选含着法、side-to-move分数和正权重。请求体最大32KiB，历史最多512着，候选最多32项，单清单最大128MiB/200万位置。请求和棋谱局面不写日志/磁盘；响应`no-store`。远端仅通过HTTPS反代，配置由用户显式提供。

## 验证边界

这是服务端协议切片，暂无数据集、客户端适配器或真实在线查询；空配置/空条目不代表有在线棋库。E71观察到“关闭/最佳着法/分差内随机”、残局云库开关及离库步数，但随机分差算法、离库行为和站点结果仍U。后续独立实现客户端超时/断网、离线缓存或本机引擎回退、合法性复核及可配置服务地址。
