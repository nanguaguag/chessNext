# ADR-042：本机动画速度偏好与落子标记

- 状态：已采纳（2026-11-03）
- 关联：F28、B23、M4-05

## 背景

E36 只观察到动画“关/快/标准/慢”选项，没有验证原站具体动画对象或时长。项目已有最后一步光圈的600ms单周动画，具备可交付的本地反馈。

## 决策

以版本兼容的 `AnimationSpeed` 加入本机 `AppPreferences`，旧schema 1缺省仍为标准；非法枚举按既有严格偏好解析失败策略处理。先将该选择应用于最后一步光圈：关=0、快=300ms、标准=600ms、慢=1200ms。该数值是项目提案，不代表源站实测。关闭动画或系统减少动画时静止，且不改变棋盘命令、引擎搜索或文档。

Material设置控件即时写入偏好并显示时长，避免只更改表单局部状态。视图仅经 `BoardDisplayScope` 读取显示值；偏好仓储仍由应用层维护。光圈只有下一次局面/最后一步变化时按新时长运行，不因设置更新而重启当前棋局或搜索。

## 未覆盖

棋子平移/吃子动画、其它视图动效、各类音效、更换资源和系统语音未实现。后续分别审计；音频使用原创并有清晰端口，不从参考站提取资源。不能据此标记 F28 完成。

## 验收

偏好旧值读取、四档往返/非法值、异步加载竞态、落子光圈快慢与关闭、系统减少动画优先、棋谱与引擎隔离、root flutter test/analyze及macOS构建运行记录均需保留。
