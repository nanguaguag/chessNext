# ADR-061：本机棋子皮肤 ZIP 导出包

状态：接受（2026-11-04）

## 背景

E43观察到皮肤编辑页有“导出”入口，但没有触发，站点导出成功语义仍U。项目已有自定义皮肤目录及用户替换图片，需要可离线备份和迁移的格式。

## 决策

- 使用ZIP封装单个用户皮肤的定义及14类可选图片槽位，包内清单schema为1；图片条目使用固定`images/<slot>.<png|jpg>`路径，并在清单中记录SHA-256。
- 导出前复用棋子图片格式/尺寸/解码校验。最多14张、总原图7 MiB、最终ZIP 8 MiB；超限或坏图整体拒绝。
- macOS经系统保存面板选择`.zip`目的地，再由私有平台端口原子写入；取消不写入。其它平台端口未实现，按钮禁用。
- 使用`archive` 4.6.0（MIT）编码，已作为直接依赖登记；不导出缓存、账户、其他皮肤或棋谱。

## 后果

项目定义包的本机生成/原子写入可测；站点精确包格式与导出行为仍U。导入、恶意归档防护、同名覆盖、在线同步不由此ADR实现，须独立定义安全约束。
