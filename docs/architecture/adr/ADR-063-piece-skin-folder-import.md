# ADR-063：本机皮肤包文件夹导入

状态：接受（2026-11-04）

## 背景

E42/E48只观察到源站有文件夹导入入口，实际格式和成功边界仍U。M4-27已定义并验证项目schema 1单皮肤ZIP。

## 决策

- 文件夹入口只接受解压后的项目皮肤包布局：根目录恰有`skin.json`和`images/`；图片目录只允许`<PieceImageSlot>.<png|jpg>`文件。该布局为项目提案P，不代表站点兼容。
- macOS系统目录选择器只读一层目录，不跟随符号链接；拒绝其它文件、子目录、链接及非白名单图片名。
- 清单上限64 KiB，最多14张图且每张512 KiB、图片总量7 MiB；转换为临时内存ZIP后，复用M4-27完整schema/摘要/真实图片解码和8 MiB压缩包上限，再经过相同用户确认和本机新增流程。
- 取消不写入；格式或读取失败不写入。不会修改所选源目录。

## 后果

本机解压的项目ZIP可通过文件夹入口导入。任意站点目录、多皮肤目录、其它平台目录选择、macOS系统面板人工视觉验收仍未完成。
