# 离线主线里程碑

| 阶段 | 依赖 | 可审查交付 | 退出门槛/当前状态 |
|---|---|---|---|
| M0 调查 | 无 | 原始站点矩阵、证据与离线范围 | 首轮完成；离线深层边界续审，不再调查登录后功能 |
| M1 技术基座 | M0 | Flutter通信spike、引擎清单、移动FFI、许可/规则ADR | macOS Flutter test与沙箱App通信已通过；移动/其他桌面/发行授权未通过 |
| M2 离线核心 | M1接口稳定；对应许可门槛在发行前 | 规则、棋树、棋盘编辑、草稿、FEN/文本 | 断网无账号新局→走棋→保存→重启恢复；规则/事务/无障碍通过 |
| M3 引擎业务 | M2 | 分析、对弈、复盘、参数与M3工作区 | 取消竞态、终局、预算难度、MultiPV、后台停止、视角和性能通过 |
| M4 离线完整性 | M3 | 多格式、导出、本地库/错题收藏、引导和外观 | 自制fixtures往返、格式损失说明、检索/恢复和可访问性通过 |
| M5 五平台发行 | M4与合规 | Android/iOS/macOS/Windows/Linux候选包 | 五平台实机安装升级/生命周期、权重授权、SBOM、完整对应源码可获取 |

M1失败不应阻止独立规则/文档设计，但不能据此宣布移动支持或原生性能达标。在线及登录后M4原计划延期，原始范围保留 FEATURE_MATRIX。
