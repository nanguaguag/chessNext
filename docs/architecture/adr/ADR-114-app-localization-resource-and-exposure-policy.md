# ADR-114：ARB翻译资源与语言选项开放策略

- 状态：接受（M4-84 / F27）
- 日期：2026-11-05

## 背景

参考站显示简体中文、繁體中文、Tiếng Việt和English；本项目现有用户文案约1,006个不同的含汉字字面量，分布在98个Dart文件，尚无Locale偏好或翻译目录。只增加选项会使大量页面、错误态和无障碍文字仍为简体中文。

## 决策

- 采用Flutter `gen-l10n`与ARB资源，资源使用稳定语义key和命名占位符，不以整句文本作为运行时翻译索引。
- 中文模板为`app_zh.arb`，English为`app_en.arb`。首个完整组件切片为界面字号对话框：可见文案、slider值、读屏标签和百分比占位同时本地化。
- 应用根暂固定`Locale('zh')`并仅声明`Locale('zh')`为支持语言；English只在独立本地化组件测试中验证，不由系统语言意外触发半翻译界面。
- 每个后续模块将其静态文案、语义/tooltip、确认、错误和异步状态逐步迁移至资源。动态用户名称、棋谱正文、PGN/FEN/UCI、协议字段、许可证原文和第三方作者内容不自动翻译；需要界面标签时由调用者单独翻译。
- 只有覆盖矩阵确认所有面向用户的路由、弹窗、错误态、菜单和无障碍文本均有完整资源并通过语言切换/持久化测试后，才增加用户可选Locale及其持久化。ARB翻译齐全本身不证明调用点已迁移。

## 验收与限制

M4-84只交付资源生成管线和字号组件切片；不声称English或F27完整。本地化覆盖清单和余下模块按F27继续推进。生成器的未翻译资源清单只检查已有ARB key，不可替代源码文案覆盖审计。
