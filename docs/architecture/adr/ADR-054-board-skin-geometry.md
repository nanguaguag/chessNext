# ADR-054：棋盘皮肤几何校准

- 状态：已采纳（M4-18），项目模型P；源站对应规格仍U
- 日期：2026-11-04
- 关联：F21、B24、E44–E47

## 证据边界

E44观察到左上/右下格点、左/上/右/下边距stepper和棋子缩放控件；E46重复左边距三次，显示左33→34.5、右465→465.06。E45确认切换落点旋转控件，但无自定义图片时效果未知。上述是源站观察/操作结果，不足以确定单位、值域、联动公式、缩放对象或旋转时序。不得将这些数字或行为冒充源站规格。

## 项目模型提案

- 新增纯Dart `BoardSkinGeometry` 值对象，存储相对于棋盘画布的归一化内部格网矩形（left/top/right/bottom），而非窗口像素或参考站stepper数值；旧/缺失配置映射到当前标准9×10格点。
- 内部格网由9列、10行交点定义。一个几何映射函数把逻辑`Square`转换为画布坐标；反向命中通过同一映射取最近交点。绘制格线、棋子、末步标记、选中框、分析箭头、局势徽标、坐标轨和拖放命中必须共享此映射。
- “棋盘显示”设置为当前本机棋盘预设提供左/上/右/下四个百分比滑杆，步进0.5%，并提供恢复默认。项目值限制每边1%…99%，水平/垂直跨度至少55%；这是本机设置即时持久化，不复制源站33/465数值，也不声称源站保存/使用入口相同。构造器拒绝非法值；偏好加载损坏时沿既有设置恢复策略处理。
- 横纵交点间距分别按对应端点线性插值。允许不同X/Y比例以适配非标准背景；命中使用实际布局尺寸转换，不使用缓存的旧屏幕偏移。flipped/mirrored只改变逻辑到视觉坐标的映射，不改变几何配置。
- 棋盘预设专属棋子缩放作为独立整数百分比，初值100%、范围80–120%、步进1%，与现有全局棋子10–200%比例及PieceSkin专属比例相乘；仅缩放棋子面容，交点命中半径与逻辑格不变。此项目P不推定E44控件语义或源站范围。
- `BoardImageSnapshot`、`BoardGifSnapshot`冻结同一几何与皮肤棋子缩放，导出不得读取预览期间更新的偏好。主盘、编辑器、图片/GIF预览共用一个呈现端口；领域规则模块不依赖Flutter。
- 几何作为当前预设的独立本机偏好即时生效，不写棋谱、不触发引擎请求；设置写入失败沿PreferencesController既有失败/重试边界处理。这里没有编辑草稿，也不将网页“保存/使用/导出”按钮语义映射成同一操作。

## 旋转另行处理（后由ADR-055交付）

落点标记图旋转保持单独切片：E45只验证开关状态从0到1。本项目实现方案和行为边界见ADR-055；不得把项目提案写成源站行为。

## 验收条件

1. 归一化几何默认/序列化/旧值迁移/坏值拒绝有纯Dart测试。
2. 百分比滑杆保持边界不变量，恢复默认及不同预设独立持久化有应用测试。
3. 正反/镜像下绘制、标记与交点命中经同一变换；坐标路数在横向与格线对齐。
4. PNG/GIF快照捕获几何；棋盘范围变更只影响显示层，不改逻辑局面。
5. 根Flutter测试、analyze和macOS实际构建/启动通过。M4-18 macOS进程已启动，但桌面自动化窗口读取超时，人工可视验收未完成，保留为未验证限制。

## 未知

源站格点/边距/缩放端点、缩放对象、四边联动关系、持久化模型、保存/使用/导出含义及落点图片旋转时机均保持U。需要新证据时按可撤销草稿路径操作并记录截图或状态。
