# ADR-090：棋盘格点拖动校准预览

- 状态：已采纳（M4-58，项目交互P；不宣称复刻站点算法）
- 日期：2026-11-05
- 关联：F21、B24、E44、E58、E64、E66、E72

## 背景与证据边界

参考站可见9×10格点与左上/右下蓝色拖点（E44）；拖动左上格点有四边数值变化样本（E58），stepper左边距变化时右值联动（E64、E72），且个别左/上输入越界会联动右/下（E66）。这些样本没有建立全局公式、精确单位、缩放换算或完整端点关系，均继续标记U。

## 决策

- 在棋盘显示设置中提供独立“拖动格点校准”对话框，预览棋盘画布及9列×10行交点网格；左上和右下拖柄分别编辑对应的两组内部边界。
- 将画布像素位移换算为画布宽/高的归一化百分比，保持现有`BoardSkinGeometry`边界（1%–99%）和最小跨度（55%）不变量。此为新项目映射P，不读取或映射参考站原始数字。
- 每次拖动变更即时交给现有偏好/皮肤控制器持久化，四个精细百分比滑杆保留以支持精确、键盘和读屏操作。校准对话框的“完成”只关闭界面；更改已即时保存。
- 两个手柄提供明确语义标签；预览说明9×10网格。手柄拖动作为额外指针操作，所有几何边界仍可由现有滑杆语义调整。

## 验收

1. 左上拖动按画布宽高分别更新左/上值，不擅自联动右/下；右下同理更新右/下。
2. 拖动不能产生越界值或低于最小网格跨度的模型。
3. 设置入口和预览不改变原设置表单可用性；关闭后即时保存值仍一致。
4. 根测试、analyze与既有macOS实例同步/热重启通过；未完成窗口可视验收时单独标记。

## 未解决

参考站完整几何算法、所有边界与输入校验规则、拖点映射和保存生命周期仍U。该项目预览不是来源站证据，也不结束F21/B24。
