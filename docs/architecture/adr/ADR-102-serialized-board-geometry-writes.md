# ADR-102：用户棋盘几何拖动的串行合并保存

- 状态：接受（M4-70 / F21,B24）
- 日期：2026-11-05
- 需求：B24 / ADR-080、ADR-090、E84

## 决策

用户棋盘几何拖动和边距输入可能在一次存储写入尚未结束时连续产生新值。过去`BoardSkinLibraryController.updateGeometry`遇到`loading`即返回失败，会丢弃后续值，导致实时预览领先于重新打开后的配置。现按用户皮肤ID保存待写最新几何；当前原子写入完成后再应用最新待写值，避免每次高频拖动都启动一个磁盘写入，也不丢最后位置。用户继续拖动期间的中间点可合并，但最终停止位置必须持久化。存储失败继续通过现有控制器失败状态呈现。

这是项目本机事务可靠性设计P，不推断参考站拖点跨轴公式、值域或保存流程。内置皮肤仍经PreferencesController自身串行偏好路径保存。

## 验收与剩余

延迟仓储测试让首次写入挂起，期间提交多个几何值，验证写入收敛到最后一个并由控制器重读到同一值；几何把手/皮肤设置/仓储专项和根门槛、复用macOS实例结果见TRACEABILITY。参考站格点完整几何模型与草稿保存应用/reload语义仍U，B24/F21开放。
