# ADR-106：已保存棋盘皮肤几何采用显式草稿编辑

- 状态：接受（M4-74 / F21,B24）
- 日期：2026-11-05
- 需求：F21,B24 / ADR-105、E67

## 决策

用户棋盘列表为每个已保存皮肤提供独立几何编辑器。格点拖动、四边数值滑杆、棋子缩放及落点标记旋转先改编辑器本地草稿；“取消”不向控制器发写入，“保存”一次提交该profile的完整`BoardSkinGeometry`。保存既不将目标profile设为当前，也不改选中内置/用户棋盘；选中状态仅由列表“使用”更改。保存失败时保留草稿并显示可重试错误。

此编辑范围覆盖E67验证的已保存几何编辑/保存/不立即应用状态。棋盘图片图层仍走现有本地图片管理流程，本ADR不定义站点文件格式或跨reload行为。

## 验收与剩余

UI测试先编辑后取消并检查定义不变；重新编辑并保存后检查几何改变、当前皮肤仍不变；单独使用后检查主盘Scope切换到新几何。根门槛/macOS复用见TRACEABILITY。源站reload/重启仍U。
