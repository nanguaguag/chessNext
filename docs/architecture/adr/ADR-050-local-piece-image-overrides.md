# ADR-050：本机逐棋子图片替换

- 状态：已采纳（M4-14）
- 需求：F21 / B24
- 证据：参考结构E41（替换入口为O，网页导入成功仍U）；项目验证见TRACEABILITY

以应用支持目录保存本机逐棋子替换图。`PieceImagePicker`与`PieceImageRepository`隔离平台和持久化，`PieceImageLibraryController`处理加载、校验、取消、替换与恢复；Material界面不直接操作文件。棋子槽位按阵营及类型固定为14项，每个PieceSkin有独立覆盖。PNG/JPEG先检查扩展名、magic、头部尺寸和真实解码，最大512 KiB、1024×1024和1MP。用户取消或校验/写入失败时保留原覆盖。

仓库使用按槽位命名的schema1清单，严格校验文件名、不跟随目录符号链接；文件先写入同目录暂存，再移入最终路径并替换清单。加载时跳过损坏清单/图片，不阻止棋盘启动。恢复默认移除清单及安全匹配的旧图。PNG/GIF导出快照捕获当前用户图片bytes。

这些格式与尺寸上限是项目的安全和内存预算决策，不是对源站未知边界的复刻。暂不包含ZIP解包、多文件/文件夹选择、在线同步、自定义皮肤元数据、棋子几何编辑或棋盘图片编辑。用户素材不上传，来源许可由用户负责；项目不带入第三方/源站图像。
