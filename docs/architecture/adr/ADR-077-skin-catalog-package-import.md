# ADR-077：自建目录皮肤包下载与本机导入

日期：2026-11-04
状态：接受

## 决策

目录包只从已配置服务HTTPS/loopback端点下载，单包上限沿用项目8MiB ZIP格式。HTTP适配器检查固定ID、预期SHA-256并在返回包前完整比对摘要。应用层再复用项目`PieceSkinPackageCodec`校验归档结构、图片大小/解码/摘要和固定路径。条目元数据名称必须与包内皮肤名称相同。

通过校验后展示许可证与署名，并要求用户显式接受后才调用本机目录导入。取消、断网、服务错误、摘要错误、格式不符及写入失败均不得覆盖既有皮肤。导入用户皮肤定义永久保存来源许可证和署名，并随本机ZIP导出。复制此类用户皮肤时保留许可元数据。

本片不添加服务端上传/投票写接口，不解释或代替法律许可判断；在线作品目录默认为空，运营者只发布有授权内容。

## 验收

摘要通过/拒绝、许可接受/取消、无写入失败保护及license/attribution本机持久化有针对性测试；真实授权线上作品尚未发布，人工macOS窗口检查未验。
