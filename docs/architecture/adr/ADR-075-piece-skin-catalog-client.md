# ADR-075：皮肤目录客户端传输端口

日期：2026-11-04
状态：接受（首片客户端传输边界）

## 决策

F21/B24 的在线皮肤目录通过 `PieceSkinCatalog` 只读端口访问，纯数据模型和网络适配器分开。第一片提供分页搜索和默认/点赞/名称/作者/最新排序，页面条目必须携带许可、署名与包 SHA-256 元数据。请求限制页码、页大小、搜索长度和最多2MiB响应；请求超时8秒。远程明文 HTTP 被拒绝，仅允许 localhost/loopback 用于本地部署验证。断网/超时、HTTP拒绝和协议错误使用不同类型异常供界面映射。

## 边界

此决策没有接入应用UI或偏好服务器地址，也没有下载/验证/导入皮肤包、缓存、点赞写入、上传、账户或跨设备同步。目录是否为空由自建服务运营数据决定。客户端不得将在线条目视为许可已经接受；后续下载确认界面必须先展示许可和署名。

## 验收证据

`test/adapters/network/http_piece_skin_catalog_test.dart`验证参数编码、许可元数据解析、拒绝非本机明文HTTP与断网错误映射。服务端契约以ADR-074为准。
