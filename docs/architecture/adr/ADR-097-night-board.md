# ADR-097：深色模式下的默认夜间棋盘

- 状态：接受（M4-65项目实现）
- 日期：2026-11-05
- 需求：F27 / E79

## 背景

E79在同一访客主界面、同一默认棋盘下，以深色模式比较夜间棋盘开/关：关闭为浅米木色，开启为明显深棕；操作后恢复系统主题和原始开关值。仅默认棋盘条件由页面说明及本次默认预设实操支持。精确色值、算法、非默认皮肤和重载持久性未知。

## 决策

增加独立的`nightBoardInDarkMode`本机偏好，默认开启。仅当实际`Theme.of(context).brightness`为dark，当前BoardSkin为parchment且`selectedBoardSkinId == 'parchment'`时，把默认棋盘底色/格线/楚河汉界标签切换到原创深棕调色。用户自定义棋盘与jade内置棋盘不变；浅色模式和深色开关关闭时保持原色。各颜色值/线条亮度是项目提案（P），只匹配E79的明暗变化，不复制参考站素材。

偏好随不可变PNG/GIF快照捕获；导出预览复用打开时的Material主题亮度与皮肤身份，避免在对话框后续设置变化导致图像漂移。UI通过应用设置表单保存；默认系统主题使用Flutter实际分辨率后的亮度。

## 验收

- 设置开关默认开、可持久化、旧偏好缺字段读为开。
- 只有深色模式+默认parchment皮肤同时满足才换色。
- 自定义皮肤、jade、浅色主题和开关关闭均原色；绘制格线/标签与背景保持可读。
- PNG/GIF快照携带夜间设置和皮肤身份。
- widget、偏好、快照专项，根串行测试/analyze/macOS既有runner运行通过。

## 未解决

参考站精确色值/算法、非默认皮肤条件、reload/restart持久性尚U。F27仍开放。
