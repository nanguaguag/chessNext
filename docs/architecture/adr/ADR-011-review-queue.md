# ADR-011 单引擎整谱队列与会话结果

2026-11-02，F32/B18，本地最佳着法复盘第一切片；源站证据E12/E13。后续彻底候选、曲线、缓存和分级分别验收。

EngineSessionController通过engine_review.dart扩展统一拥有EngineGateway；复盘不创建第二进程。开始队列先停分析/AI并等待屏障。分析、AI、全局资源调整、后台停止可取消队列；取消保持stopping直到stop完成，迟到info/bestmove丢弃。取消不自动恢复AI/分析。

ReviewRun捕获不可变GameTree、epoch、内容revision、范围和有限预算，单线路包含未来着，整树每节点一次；子节点先处理，过程不移动棋谱游标。纯阅读允许继续工作；任何内容修订或文档替换使结果stale并停止，包含注释/置顶的保守失效策略，不冒充参考站缓存规则。完成结果也在文档变化后明确过期，禁止跳转到复用ID的新文档。

ReviewLimits复用EngineRequest策略边界，depth/time/nodes可组合，至少一项有限。UI的0转换为null，不把三个0传成无限队列。资源使用现有能力钳制后的Threads/Hash，单路PV；每次搜索保留完整根FEN和历史，文档gameId沿用epoch，保留TT复用。

每局面保留原始cp/mate/bound、执方、深度/PV等EngineInfo，展示独立换算红视角（黑侧界限反转）。无info、终局、合法评分分别区分，未取得评分不写0；完成队列不等于所有节点获得评分。取消仅保留完成节点，运行节点不冒充完成结果。搜索失败有failed状态，可重试；不输出未经校准的准确率或等级。

结果目前只保留本机当前会话内存，不存进GameTree/显式棋谱/草稿。尚无缓存键/跨重启复用，不能宣传已完成整谱持久化。未来缓存需引擎/NNUE身份、规则、完整历史、预算和算法版本，独立端口，不混入导航元数据。

UI为features/review；选项对话框独立State拥有控制器、校验NaN/全0/极值、可滚动大字，结果有界列表可跳转。不直接调用进程或IO。真实OS焦点和其他四平台另行验收。
