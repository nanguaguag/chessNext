# ADR-042：动态图使用冻结线路、独立GIF端口与有界隔离编码

- 状态：已接受（M4-04）
- 日期：2026-11-02

## 决策

动态图捕获`GameTree.currentLine`的根到所选末端，不读取旁支或生成期间的Session。显示偏好和双方向同时冻结。最多64帧，超限显式拒绝；不以静默截断冒充完整线路。

Flutter渲染保持原创BoardSurface，输出450×540；PNG中间帧只在内存存在，`image 4.12.0`在Isolate量化并编码GIF。输出由`GifImage`执行GIF头、尺寸、帧时长和12MiB边界，macOS再用ImageIO独立验证。GIF文件端口与静态PNG、图片剪贴板和文字文件分开，UI不接触文件选择、MethodChannel或Foundation。

首帧使用开局停留、末帧使用终局停留，中间帧使用步时；首尾替代而非叠加，来自E35区别时长实证。单帧只用开局停留是项目定义。标题最长60字符、固定输出尺寸和资源预算也是项目定义，不声称参考站同限额。

## 后果

优点是线路/竞态边界可测，编码不会阻塞主Isolate，平台可替换且坏文件不覆盖目标。代价是64帧以上必须先缩短所选线路，首版没有系统分享和其它平台保存；逐帧Flutter栅格仍需真实macOS验证，不能只靠注入组件测试。
