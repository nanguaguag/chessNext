# ADR-004 离线主线与通信验证范围

日期：2026-11-01。状态：接受（范围与桌面验证）；移动端运输仍待验证。补充 ADR-001/002，不宣称其移动部分已接受。

用户将登录后功能延期，要求先完成本地离线引擎能力。本轮授权独立 Flutter 最小通信 spike；完整棋盘业务不在本轮实施。保留 F/B 旧编号，新增 B13–B20 表达离线增量。

桌面 macOS arm64 已在 Flutter 测试环境驱动官方 2026-09-06 二进制，NNUE/MultiPV/限时搜索/100轮 stop/退出通过。采用桌面 Process 作为第一条验证路径。Windows/Linux 未验证；移动端 C ABI 仍提案，iOS不得假设可运行子进程。

离线不依赖云库结果、认证或远端下载。开发用手动安装网络；发布前选择可合法捆绑的网络或获得权重授权。当前发行包 NNUE 的非商用限制使“所有制品均自由开源”的目标尚未满足。

难度仅按固定节点/时间预算设计可解释分级，不假设引擎含 Skill Level，也不宣称等同网站0–20棋力。准确弱化算法与等级校准另立实验。

macOS App进程亦已验证：helper放入Resources，签名带app-sandbox+inherit，App保留Sandbox；NNUE/MultiPV/3轮stop/退出通过。直接执行仓库外helper会失败，因此生产打包必须覆盖helper签名与网络路径。沙箱内共享内存回退为本地分配，未测性能影响。
