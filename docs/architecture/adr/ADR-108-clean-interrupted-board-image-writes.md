# ADR-108：读取棋盘图片时回收已知的中断替换产物

- 状态：接受（M4-77 / F21,B24）
- 日期：2026-11-05
- 需求：B24 / ADR-056、107

## 决策

棋盘图片替换使用每槽临时目录、新数据文件、原子槽清单替换的顺序；进程可能在清单切换前退出。加载时只针对无槽清单或已成功解码并通过图像校验的槽，回收本应用格式中的、未被当前清单引用的`slot-timestamp.(png|jpg|jpeg)`图片和`.slot-pending-*`临时目录。只清理固定槽位名与格式匹配且经`followLinks:false`确认的普通文件/目录。任意未知文件保留。

若槽清单存在但无效、是链接、引用图片缺失或图片损坏，则不做该槽回收，保留原数据供恢复/排查。内置及用户皮肤使用相同槽级规则；皮肤目录层级回收仍由ADR-107处理。

## 验收与限制

测试创建有效当前图像、已知孤儿、遗留staging目录、未知文件及无效槽清单，加载后仅删除前两类允许清理的中断产物。该逐槽清理不是图片文件与manifest的跨文件原子事务。详细门槛见TRACEABILITY。
