# ADR-059：用户棋子皮肤独立大小与位置

状态：接受（2026-11-04）

## 依据

E43 在新建棋子皮肤编辑页观察到大小滑杆、方向移动、自动对正和归零；观察到大小初始50、最右70、左侧约20.5以及右移一次显示“右1”。端点、精度完整边界和保存/使用成功均未验证；不得把这些读数当作实际规则。

## 决策

本机用户皮肤分别保存棋子面容比例和横/纵偏移。项目边界P：比例80%–120%，1%步进，默认100%；偏移各自±8%格宽，方向按钮1%步进，自动对正回0。新皮肤从当前皮肤复制这些参数。主棋盘与局面编辑器使用选中用户皮肤值，叠加现有全局棋子比例并保持逻辑交点命中；PNG/GIF快照捕获相同参数，不追踪后续编辑。内置两预设保留现有偏好字段，不做数据迁移。

## 未包含

阴影仍沿用基础内置皮肤值；每子图片、棋盘关联参数、库排序/搜索/导出、ZIP/文件夹导入和在线目录仍在B24。源站保存/使用效果和端点继续为U。
