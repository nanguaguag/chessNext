# ADR-084 按引擎线程自动分配置换表内存

状态：接受（M4-52）；关联F24/B25及参考证据E69。

本机分析设置可选择手动Hash或按线程自动分配。自动模式将目标Hash设为线程数×64MB，并在PreferencesController按真实EngineCapabilities、设备线程数与已有应用上限钳制；更改线程会重算Hash。手动模式保留用户指定Hash。用户从分析参数面板直接改变线程/Hash时退出自动模式，避免后续静默覆盖其显式选择。自动模式本身和有效Hash均保存于本机偏好。

E69只验证参考网页默认每线程64MB及线程联动。项目保留既有手动偏好作为安全默认，不把浏览器推荐上限、线程数量或SIMD文案复制到桌面/原生引擎。新增可选`autoHash`字段；历史schema1配置缺失该字段时解释为手动模式，保留既有Hash，不做资源放大迁移。实际限制仍由UCI握手能力/平台约束决定。

验收：自动模式线程联动、能力钳制、旧偏好兼容、迟到读取合并、手动模式与本机持久化均需覆盖；根Flutter测试、analyze通过后再复用唯一macOS runner验证。
