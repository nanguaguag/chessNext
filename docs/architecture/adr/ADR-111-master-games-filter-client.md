# ADR-111：大师谱筛选客户端

- 状态：接受
- 日期：2026-11-05
- 范围：F15、F20、M4-81

## 背景

E86/E87只确认筛选字段入口及可见DOM年份声明。查询时机、匹配排序、分页、数据内容与站点授权均未知。M4-80已提供operator自供索引服务端，但Flutter尚无筛选UI/客户端。

## 决策

在云库面板中增加“云库／大师谱”来源切换。大师谱过滤字段包括全部/对局/棋书、棋手或赛事、起止年、红胜/和棋/黑胜。只在用户显式按查询后，向已配置的自建服务发送当前FEN、完整当前线路及筛选条件；输入和切换不发请求，空地址离线。结果只展示索引metadata、数据集许可署名和分页，不落子、不改变棋树，也不拉取完整棋谱。

Flutter端口与HTTP适配器独立于UI，限制请求32KiB、响应2MiB、超时8秒、HTTPS远端/HTTP loopback；校验schema、页码、来源字段、记录字段和值域。位置或过滤变化使旧请求失效。

## 后果与限制

- 筛选字段来自可见站点入口；字段匹配、默认排序、分页大小、提交语义均为项目P，不代表源站实现。
- 数据集必须由运营者自供且有权提供；仓库不包含任何棋谱样本。服务端元数据查询不等于完整棋谱读取，后续单独实现。
- 来源切换仅为当前主工作区组件状态，不声明跨进程持久化。
- 未配置endpoint时无网络请求；没有登录依赖。
