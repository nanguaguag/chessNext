# ADR-049：本机棋子预设及跟随音效

- 状态：已采纳（M4-13）
- 需求：F21、F28 / B23、B24
- 证据：E37、E40、E41、E42

提供两套原创、无外部资源的本机棋子外观预设：传统圆章（沿用既有圆形棋子）和方章墨韵（柔角方形、淡墨边框）。偏好默认传统圆章，schema1稳定枚举兼容旧设置；两套样式通过BoardDisplayScope贯通主盘、局面编辑与PNG/GIF冻结快照。选中/焦点/命中/朝向等行为不受外观切换影响。

“随棋子皮肤”走棋音效在播放前由应用层解析成音效1或音效2：传统圆章→1，方章墨韵→2。AudioFeedbackPort仅接收已解析的MoveSoundChoice，不依赖Flutter或棋盘皮肤模型；本机自定义事件音效仍在适配器优先级最高。方案弹窗“当前”摘要与试听使用相同的皮肤偏好解析结果。用户选定音效1/2时，不受棋子皮肤变化影响。

这一映射是项目设计，不声称源站素材或声音相同；不复制远端图片/声音。用户图片替换、导入、ZIP多套选择、编辑器和完整皮肤清单继续由B24设计实现。验收证据见测试/TRACEABILITY。
