# ADR-104：删除当前棋盘皮肤时先提交定义变更

- 状态：接受（M4-72 / F21,B24）
- 日期：2026-11-05
- 需求：B24 / ADR-080、E60、E61

## 决策

删除用户棋盘皮肤时，先将移除后的定义清单持久化；只有成功后，才更新运行时列表、将当前选择回退到其内置基底并清理图片。若清单写入失败，当前选择、用户定义和图片均保留，避免一次失败操作仍改变正在使用的棋盘。清单已提交但图片缓存清理失败时，定义仍视为已删除并向用户报告缓存清理问题，残余文件不再通过目录可见。

## 验收与剩余

使用失败注入仓储，在当前选中用户皮肤上让manifest保存失败；验证删除返回失败且当前ID、目录清单、图片保持原样。成功与图片清理异常边界见测试。参考站删除/恢复及reload行为只依据各证据条目，不由本机事务设计推断。
