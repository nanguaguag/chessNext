# ADR-005 本地棋谱仓库的首个持久化适配器

日期2026-11-01。状态：接受当前单窗口macOS阶段，不替代后续存储性能和多窗口验证。

GameRepository端口隔离UI与存储。首个实现为应用Documents目录下的版本化逐棋谱JSON快照，保存棋树根FEN、稳定节点、分支顺序、注释、游标与ID序列；不保存冗余局面，以合法走法重建并拒绝损坏/循环/孤立节点。限制4MiB与2000节点，未知schema拒绝，不静默升级或丢弃字段。

macOS在同一文件系统内写临时文件、flush后rename提交；覆盖前保留可读取的旧版备份，主文件损坏时回退并提示。读取不改原文件，损坏记录在库中报告。该实现不宣称文件夹fsync级断电保证、Windows同等语义或跨进程写事务。

SQLite/Drift仍为未来索引/多文档事务候选，不为首个保存功能引入迁移框架。接口保留替换能力。path_provider2.1.6用于平台Documents路径，来源/许可证/hash记录于依赖清单与pubspec.lock。

内容revision决定dirty；positionRevision用于防止异步打开覆盖中途导航；epoch区分新建/载入的文档身份。晚到保存只可标记对应epoch与revision，不能把新局或后续走子误标为已保存。生产注入FileGameRepository，组件测试显式使用内存预览适配器。
