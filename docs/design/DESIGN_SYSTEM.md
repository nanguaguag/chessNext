# Material Design 3 设计规范（提案）

使用 ColorScheme、语义 typography、Material 3 导航/按钮/菜单/滑块/对话框；[Flutter Material 3 API](https://api.flutter.dev/flutter/material/ThemeData/useMaterial3.html) 当前默认启用 M3。棋盘为独立绘制与命中测试组件，提供 Semantics，不能仅画 Canvas 丢掉可访问性。

色彩用 primary/onPrimary、surface/onSurface、error 等角色；红黑棋子与正负分数保留文字标识，推荐箭头同时用形状/标签区分。自绘资源必须原创或许可明确；暗色模式保证棋盘与棋子可辨。

布局按可用宽度而非 OS 判断：<600dp 棋盘+底部 NavigationBar/分页面板，600–839dp NavigationRail，≥840dp 双/三栏分析工作区。断点为待验证初值。分隔条键盘可调、最小宽度防溢出，重置恢复默认。棋盘保持9×10交点比例，触点扩展到可操作区域；最小触控目标48dp。200%文字仍可滚动且不遮棋盘操作。

Android 支持系统返回/预测返回和边到边安全区；iOS 支持安全区、返回手势和系统分享/文件选择；macOS 使用 Cmd 快捷键和窗口菜单；Windows/Linux 使用 Ctrl、焦点导航和标准窗口行为。M3 保持统一，系统对话框由平台适配器提供。

键盘：方向键移动棋盘焦点，Enter/Space 选子/落子，Escape 取消选中/关闭浮层。快捷键通过 Shortcuts/Actions 注册，避开文字输入；撤销和新局不得悄悄删除未保存棋谱。读屏播报方色、棋子、坐标、选中、非法原因与轮到谁。

分析页提供 idle/loading/running/stopping/failed；云库有 loading/empty/offline/unauthorized；库有空草稿/加载/失败/迁移失败。尊重减少动画、系统字号、音量；后台停止高耗能搜索。视觉验收包含明暗、字体放大、横竖屏、鼠标/键盘/触屏和读屏。

M3-19已实现TextSizeDialog：标准100/大115/特大130和系统开关，实时生效/错误重试/本机记忆。AppTextScaling在所有Navigator路由统一MediaQuery，系统TextScaler原对象保留，手动线性覆盖而非叠乘。200%系统下窄窗滚动/语义/键盘滑块已组件验证，棋盘命中几何不因字号改变；其它平台真实OS行为待验。

M3-20棋盘坐标边框：上下红黑路数各为只读语义组，标签FittedBox适配200%与窄窗；90交点的绘制/点击/拖放共享内部格距，边框位于格子外，不用屏幕坐标缓存定位逻辑着法。全框/内部棋盘均9:10，显示变化不改领域方位。此为项目设计，不复制参考素材或被棋子遮挡的标注布局。

M3-21棋子大小10–200%、步进5、默认100；仅面容与拖动反馈缩放，交点命中/读屏标识与格距固定。超大值允许棋盘内重叠裁切（与E23观察一致），设置中解释这一显示效果；默认重置只影响尺寸，不改变坐标/字号。

M3-22推荐箭头组合开关同时控制蓝色本步与紫色预计应着，保留分析PV与计算；尖/标准/宽只改头部，画层在棋子下且不截获触点，提供只读推荐/应着语义。头宽为项目自有几何，非源站像素算法。

M3-23绿色变着箭头从上一局面起点指向本步同级终点，编号与列表对应，非当前下一着推荐。两层开关都开才画，局部只会话状态；图层不拦交点且提供只读编号记谱语义。64条绘制预算保留当前原编号，列表完整；全局关时局部区域说明关闭位置。

M3-24局势条提供方色文字、模型说明Tooltip与非live只读语义，灰态不伪造均势；20dp+8间隔隐藏可回收，横向滚动最低492/464维持交点约48dp。原生模型预期得分随棋盘旋转，缺失/边界/杀棋各提示，实际终局另标。

M3-25最后一步源圆环/终点分段光圈或四角框，双描边提升木纹与明暗辨识，独立只读语义/不拦点击，不跟随棋子尺寸缩放。600ms单周旋转后静止、系统减少动画中断，方向变换不重启。

M3-26选子抬起上移8%格距/增强阴影，或固定交点绿色四角双描边框；不改变命中/合法目标/selected语义。框不随棋子尺寸伸缩，编辑器共用；拖动反馈无选择态，无新增ticker。

M3-27历史面板捕获打开时列表与评分方色，虚拟化可选择文字、界定模型/评分边界/截断，不随搜索抖动；清空入口仅当前展示，不改计算。200%字号长PV实际滚动末端/Escape已验。

M3-28只读预览按宽度分栏或上下；单组局面语义/排除90格禁用按钮与焦点干扰，方向键和点着/首尾/0可用。虚拟列表行高随TextScaler，800ms主动播放/暂停/失活退场停；来源评分和未写谱提示明确。

M3-29预览提供显式走到棋盘上，说明暂停计算和选定前缀；0/来源过期/忙态禁用，忙态停播放且关闭可取消未提交操作，成功返回主棋盘，错误保留并解释。200%失败/重试与两route退场已组件验证；原生完整32过，不等于OS人工视觉。

M3-30历史显示来源步数/着法，避免混为当前分析。200%源stale说明导致棋盘81.6px的实测失败已修：窄/短/大字号整体滚动、300px棋盘区域和200px独立虚拟步表，宽高够分栏；错误自动滚入视区，保证测试>=240px棋盘可辨认及无溢出。

M3-31当前着评级用原创Material图标角徽与文字图例；固定交点34%格距/右上偏移28%，翻转镜像共享逻辑坐标，不随棋子缩放、不拦点击、不新增动画。语义附实际格，图例滚动覆盖200%；全局隐藏只徽标，损失数字保留。

M3-32复盘方式选择立即生效/取消后保留，对话框展示本机保存失败与重试。重新分析默认关跳过，明确该开关仅本次任务；200%窄窗表单滚动，不自动启动计算。

M3-33容量提示解释含根2000局面和保存/导出/删枝后继续，满容量已有路径仍可读。候选SnackBar明确容量，主盘通知可滚动适配200%；AI暂停保留本机分析，不使用引擎损坏提示。

M3-34主盘左右翻转使用Material按钮/toggled语义/只改显示Tooltip，触点最小48dp，与旋转组合复用交点坐标。镜像不缩放命中，200%与10–200%棋子仍按逻辑格操作；PV小盘固定打开时双方向。

M3-35 PGN提供默认开的后续着法复选框与到当前阅读点说明；与评注选项独立，200%可滚动，busy禁改。默认包含未来遇不可表示评注时明确错误/禁用复制保存，显式缩小范围或省略评注可恢复。

M4-02图片导出使用450×500逻辑尺寸的只读棋盘预览和2倍PNG，不复用参考站素材。预览合并为单组语义并排除90格焦点，冻结打开时主题、系统字号、减少动画、方向和显示Scope；200%窄窗由Material滚动对话框承载。保存busy时仍可关闭，退场取消尚未开始的选择或写入，已经开始的原子写不伪称回滚。

M4-03同一图片对话框提供复制图片与保存图片，二者共享首次PNG生成缓存并在任一操作busy时互斥，关闭始终可用。无平台能力时各自禁用并解释；复制成功、取消和失败用独立状态文案，失败可重试且不重新渲染已缓存图片。200%窄窗操作仍随AlertDialog滚动可达。

M4-04动态图对话框使用Material 3文本框、三条带秒数语义的Slider、线性进度和生成后动画预览。450×540原创画面固定无系统字号/动画干扰，底栏标题单行省略并始终显示第N/总帧；外层表单遵循全局字号并可滚动。生成/保存busy时参数和动作禁用、关闭可用；64帧/12MiB限制、完整线路和首尾替代语义必须可见，不能在后台静默降质或截断。

M4-05 落子动画速度为 Material 3 单选分段控件，关/快/标准/慢均有明确语义与毫秒摘要；设置即时本机保存。`MediaQuery.disableAnimationsOf` 的系统减少动画始终覆盖项目速度偏好，速度切换本身不触发既有棋步动画。

M4-06棋盘显示设置中提供单独的“走棋音效/选子音效”Material开关，解释本机离线行为。开关即时保存；无系统/插件音频时仍保持棋盘可操作。当前原创提示音简单且短，不能将其写成可选择音效库或源站音色。

M4-08设置提供独立“着法朗读”Switch，默认关，与走棋音效分开解释。仅已安装的本机中文语音可用时朗读；未安装或平台不支持时保持静默，棋谱输入仍正常。

M4-12棋盘皮肤先以Material3 DropdownButtonFormField提供“宣纸木色”和“松石青”原创配色，设置即时保存；不从网页获取图像。语义颜色分别作用于板面底色、线条、楚河汉界字、棋子面和边框，选中/焦点/合法目标标记使用独立状态色。棋盘快照捕获所选配色，关闭再打开不可变化。

M4-13棋子预设用Material3 DropdownButtonFormField提供“传统圆章/方章墨韵”，分别以圆形/柔角方形呈现；默认预设保持原棋子外观。选中、焦点、合法目标和棋子朝向在两种预设下保持语义与可操作。走棋音效跟随预设使用音效1/2，弹层的试听与状态摘要一致。

M4-14在棋盘显示设置提供“编辑当前棋子图片”入口，采用Material3可滚动对话框列出红黑14类棋子。每行有替换/恢复默认动作、现图缩略预览及busy/错误状态；单槽处理时其它替换动作禁用，关闭按钮可取消并返回棋盘。无图时显示类别名与默认图形。选择文件后校验失败展示可读原因，保留现图。文件过滤器仅PNG/JPG/JPEG；真实文件选择平台能力需逐平台验收，当前已实际构建运行macOS。

M4-15设置在当前棋子皮肤选择项下展示独立缩放滑杆，80–120%、每1%一步，默认100%；当前样式名称与数值在标签中明确呈现。它和原全局10–200%大小分开存储、按乘数作用于棋子面容，交点和命中区域固定。圆章/方章各自偏好，切换下拉后滑杆即时载入另一套值；访问性格式器读出百分数，恢复默认走回100%。

M4-16继续在当前皮肤下显示十字方向移动控制：上/下/左/右语义tooltip，中心“棋子自动对正”；每点击一次在对应方向移动一个棋格宽的1%，边界±8%禁用相应方向。数值文案明确横纵偏移，圆章/方章分别记忆。变换只平移绘制层并关闭transform hit tests，棋盘格子和逻辑落点固定；超出当前皮肤预览不会影响真实棋局布局。
