# ADR-101：版权投诉的显式证明图片附件

- 状态：接受（M4-69 / F31 项目切片）
- 日期：2026-11-05
- 需求：F31 / E74、E81

## 决策

版权投诉表可选由用户经平台文件选择器显式选择PNG/JPEG图片，最多3张、单张≤256KiB、合计≤512KiB。限制值和传输schema为本机项目契约P；参考站可见附件入口和最多3张声明为O，未测试真实上传/接收。表单显示图片缩略图、名称和大小，支持移除；提交前展示完整投诉字段、目标地址和所有附件名/MIME/字节数。预览/取消均不产生请求；只有再次明确确认才向已配置服务提交。不会自动截屏、抓取网页、采集棋谱或读取设备文件。

投诉数据包含识别与权属说明，服务端继续使用独立于一般反馈的`CHESSNEXT_COPYRIGHT_ROOT`私有目录和最多1,000条记录上限。附件仅以base64写入这条私有记录，无公开读/列/下载API。投诉JSON体积上限768KiB，样例Nginx投诉路由允许1MiB。运营者须先定义访问控制、留存和删除策略；本项目不代替法律处理流程。

## 验收与剩余

Widget测试验证预览前不发送、图片进入确认预览及显式确认后随投诉提交；HTTP测试验证只发送明确附件；服务端测试验证隔离存储、无公开读取及非法路径拒绝。Root与服务端门槛、既有macOS实例验证见TRACEABILITY。生产投诉服务部署/运营者访问删除/留存、外部交流入口及真实投递仍待办，F31开放。
