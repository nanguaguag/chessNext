# ADR-012 精确条件复盘缓存与失败降级

2026-11-02，F32/B18。当前接受有界会话内存实现，持久文件适配器下一独立切片。参考E12/E13仅证明跳过功能，不证明网站缓存键，以下为项目设计。

ReviewCacheRepository隔离应用与存储，CachedEngineScore只存完成单路、无bound、非空有界PV的引擎评分，去除token，不含文档ID/节点ID/游标。MemoryReviewCacheRepository最多2048条LRU，读命中更新顺序。当前退出丢失；UI和文档不得声称已跨重启保存。

reviewCacheKey用SHA256计算固定序列化的schema/算法/规则版本、已校验EngineIdentity、规范根FEN、完整相关走子历史、depth/time/nodes、Threads/Hash/MultiPV/searchMoves及排序后的其他UCI选项默认值。排除epoch/token/游标/lineAnchor/注释；不按末局面或显示名复用，也不把更高深度推定为当前预算等价。当前适配器只更改资源及EvalFile，其余保持握手默认；未来规则/选项实际可变时必须升级键并传入真实值。启动队列先完成握手再生成键、钳制资源。

开始复盘默认跳过已有；关闭后强制重新搜索。身份未知允许计算但不复用。终局/无info/带bound结果不写成完整命中。复用前验证key及完整PV在目标局面合法，缓存评分不经活动info事件路由。文档注释变化虽使当前ReviewRun过期，但重新发起相同内容计算可命中正确历史。

取消/过期检查包围异步缓存读写，旧结果不进入新任务。单次缓存IO超时2秒；读取/保存失败时本任务剩余节点停用缓存并真实重算/继续，显示明确提示，不牵连棋谱/草稿，不把缓存失败等同引擎失败。缓存不是已保存棋谱。强制重算若没有新完整评分，旧的完整缓存仍可保留；取消当前正在计算的节点不冒充完成节点，已完成节点可复用。

跨重启适配器仍须实现独立ApplicationSupport目录、schema/大小/总量/路径验证、损坏降级和原子替换；缓存可再生，无需复用棋谱备份机制。该阶段未完成前保持内存事实。
