# ADR-052：本机棋子皮肤位置微调

- 状态：已采纳（M4-16）
- 需求：F21 / B24
- 证据：E43观察四向按钮、自动对正和偏移/复位状态；精确单位未知

传统圆章和方章分别保存X/Y整数偏移。项目选定每次±1棋格宽百分比、上下限±8%、默认0（P）；这是明确、安全的本地预设而不是声称复刻站点范围。调整作用于每个棋子绘制层，使用视觉坐标（屏幕上/下/左/右），不改Position、逻辑Square、棋谱/引擎请求或90个交点hit-test。界面只读PreferencesController并通过其入口保存，边界按钮禁用，自动对正恢复两轴0。

`BoardDisplayScope`只读传递当前预设两轴偏移。图片/GIF snapshot捕获偏移因子，导出渲染同样按棋格宽比例平移。值可使棋子超出面容中心或视觉重叠，但不会遮蔽邻格输入，因为transform关闭命中测试。阴影模型和棋盘图形定位另行设计。
