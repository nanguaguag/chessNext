# ADR-031：PV历史按当前局面采样，独立于持久缓存

2026-11-02，E24/E30确认历史卡和停止保留，原站清理/上限未知。当前片只交付只读列表，下一片预览播放，不设置未接通按钮。

纯AnalysisHistory/PvHistoryEntry拥有有界展示样本：最多64条、每条128步；深拷贝不可变PV，源Position/epoch/nodeId/内容与位置修订、原始score/bound/WDL/深度/token完整保留。较长PV明确截断，raw PV不在流接收处做高成本全线合法性重放；下一预览必须先有界验证，不能将仅文本展示当合法可执行路径。

EngineSessionController在现有100ms普通分析提交处采集，按各PV最新内容去重（忽略仅时间速度变化）；不订阅新流/启动新引擎，不改变AI/复盘所有者。换位置清空，停止或同位置重启保留，旋转与资料不清。显式清空只影响展示，后续有效新事件可重建，不改文档或搜索。历史不写用户库/草稿/偏好或分析结果缓存。

AnalysisPanel计数/清空入口，打开前捕获不可变列表与方色，PvHistoryDialog使用虚拟列表/可选择UCI全文/原始评分按源局面归一、bound和mate0如实说明。对话框后续不跟新数据抖动，当前分析继续；不提供未经实现的预览入口。

采样/预算/换局面清理为项目P，非网站同策略声明。预览播放/应用PV前缀、AI搜索PV历史、hover/触控和其它平台后续独立验证。

2026-11-02 E31补证：原站在前缀提交与回退后仍有1368旧历史，原“跨位置未知”收窄。当前局面清空是已知差距，规划后续独立修订保留有界来源快照；不改写本ADR已实施历史。
