# ADR-066：本机侧栏面板显隐

- 状态：接受
- 日期：2026-11-04
- 需求：F20 / B25（E50）

## 背景

参考站操作设置中可切换若干面板显示（E50，O），但项目选项的具体源站对应关系、记忆周期及隐藏时切换方式未验证（U）。项目已有四个独立分析/对弈侧栏卡片和全局设置入口。

## 决策

在`AppPreferences`中以稳定`SidePanel` ID保存可见项子集；缺字段表示四项全显示。列表可为空，但不允许重复/未知项。主侧栏只构造启用的卡片；顺序继续由ADR-065独立管理。所有面板可关闭时，AppBar设置入口仍保留，用户可恢复。开关经PreferencesController即时写入本机，不影响棋局、引擎、模式或数据。

这只是项目四卡片映射（P），没有实现参考站独立“棋谱栏”“面板切换栏”或云库可用性。

## 验收

- 旧schema默认显示全部；可见ID列表严格去重且可空，存储往返。
- 延迟读取期间修改可见集合，迟到数据不覆盖用户最新修改。
- 隐藏卡片后主界面移除其子树，其他卡片仍工作；设置可重新启用。
- 根目录Flutter测试、静态分析和macOS Debug运行通过。
