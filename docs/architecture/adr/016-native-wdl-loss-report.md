# ADR-016：原生预期得分损失与可追溯着法评级

2026-11-02，F32/B18。已实施，验收见TRACEABILITY。参考E12仅证明界面阈值2/5/10/20及展示；源站等号、准确率聚合、妙手/唯一守招/错失杀棋公式未知，不能宣称同算法。

## 选择

纯应用层ReviewReport从用户打开时的不可变ReviewRun快照计算一次。算法native-wdl-loss-v1：走子方原生预期得分=(2*wins+draws)/2000；父局面最佳预期减实际着预期，小于0钳0，最大100%。原生统计是引擎模型估计而非实战获胜保证。统计不从cp拟造。

实际着优先采用**已完成父局面候选组**中匹配着法的精确WDL，否则采用**已完成后续局面**的WDL换算走子方视角。都来自同一复盘运行的身份、资源和预算；搜索深度/有限用时采样不等于数学真值。合法规则终局直接采用胜1/负0（包括困毙判负）。父或后续完成记录缺失、视角不匹配、必要WDL缺失、所用评分仅上下界均不评级；父/后续或匹配候选杀棋留专门评估，不当普通概率。

整数损失单位为0.05个百分点，避免浮点阈值：零损失且命中父局面首选=最佳；<2%=优秀；[2,5%)好着；[5,10%)不精确；[10,20%)错误；≥20%败着。此等号及聚合是项目明确版本的选择，仍非网站准确率。红黑分别显示已评级/总着、问题/未评级、**已评级着法**平均损失；分母0显示暂无数据。整树范围含分支着法，不伪装一条对局。

## 界面与失败

Material3报告对话框标明算法版本、开窗快照、范围及partial；支持双方/单方、只看问题与所有着法，有界虚拟列表、200%字号、Tooltip说明数据来源/前后预期。未评级不算正确。报告只读，行跳转经唯一EngineSessionController；调用前后核验epoch+内容revision+稳定节点ID，新文档复用ID不跳转，过期入口禁用。开窗后后台复盘变化不自动重算，不每100ms扫描全树。没有持久化报告或自动收集错题，本地训练属于下一独立增量。

## 验证与局限

阈值/双方视角/同父候选优先/partial/空分母/无WDL/bound/mate/视角错配/困毙、组件筛选/跳转/新文档ID复用/200%字号及真实macOS NNUE报告操作。具体命令和结果追踪表为准。历史长将长捉规则未实现，不借报告宣称完整裁决。仅macOS原生验证，其它平台仍待验证。
