# ADR-028：局势条采用明确的原生模型预期得分

2026-11-02；E26确认站点显隐/方向/停止保留，未证比例公式，项目不复制推测公式。

BoardEvaluation是无Flutter投影：实际领域终局优先；仅首PV、普通无bound且有原生WDL时按执方转换到红方，以2W+D的0–2000整数表示胜加半和。缺失、非首PV、无WDL、bound和mate为不同灰态及文字，mate0不猜胜方，真实终局全胜颜色不称模型估计。GameMetadata.Result不参与局面裁决。

EngineSession现有位置修订清信息负责防旧局面渗入；停止后保留同局面最后结果，模型文字明确保留快照。EvaluationBoard只呈现，没有进程/存储依赖。默认可选showEvaluationBar字段与偏好Controller合并/持久化/重试，隐藏不改搜索/文档；编辑器不带引擎条。

条与棋盘同高，红黑方向随flipped，文字方色/Tooltip及只读语义，缺失问号而非50%。显示占20+8dp并可回收；滚动区最小总宽492或464，保证现坐标边框下约48dp交点，内部9:10和统一命中不变。状态更新不设liveRegion，避免搜索期间连续朗读。绘制无动画，不额外开计算。

WDL是本机模型期望而非实战胜率/网站公式。其它F26着法标记、B22历史及各平台真实视觉/OS行为仍后续。
