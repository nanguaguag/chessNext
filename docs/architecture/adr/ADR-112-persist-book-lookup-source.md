# ADR-112：记忆主界面云库来源

- 状态：接受
- 日期：2026-11-05
- 范围：F15、F20、M4-82

## 背景

E55操作验证主界面/设置中有独立“云库/大师谱”来源选择，并在同标签页导航后保留。M4-81仅将选择保存在工作区widget状态，离开工作区会复原为云库，不符合已验证的保留边界。

## 决策

新增版本化偏好`bookLookupSource`，默认`cloud`以兼容既有设置；`masterGames`选择跨路由和App重启保存。设置页和主面板共用同一值。用户切换来源只改显示/查询模式，不自动联网；每种来源仍由独立显式查询按钮触发。偏好读取期间用户先行选择按既有逐字段merge规则优先。

## 后果与限制

- 来源选择持久化是对E55保留行为的项目实现；不代表源站页面重启持久性已验证。
- endpoint仍可空且不请求；本决策不改变数据授权、查询语义或服务器协议。
