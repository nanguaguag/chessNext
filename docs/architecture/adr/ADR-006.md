# ADR-006 自动草稿独立快照与显式恢复

状态：接受首个macOS单窗口实现，2026-11-02；关联B16、F10/F18本地连续使用。

自动草稿属于工作副本，不等同于棋谱库显式保存。通过DraftRepository独立端口，在Documents/chessnext-drafts保存active版本化快照；复用FileGameRepository校验/临时提交/备份机制，不写chessnext-records。修改/导航/标题以300ms去抖，异步写入串行化，写入过程中后续修改排队为最新不可变快照；失败不清dirty。

初始化发现草稿时暂停写入并提示恢复或使用当前棋谱。恢复创建新dirty文档、不绑定原保存ID；原棋谱文件不会被覆盖，AI角色和自动落子不恢复。读取期间的新操作不被静默覆盖；当前dirty需确认替换。空白新局也可写作检查点，防止下次启动复活已经主动清除的旧局；空检查点不显示恢复提示。

备份恢复标注来源；原文件损坏且用户继续当前棋谱写入时，将损坏原件保存在隐藏.damaged目录，不用损坏主文件替换已知备份。草稿仅一个当前版本加备份，不承诺多文档历史、跨进程写入或目录fsync的断电持久性，继续遵守ADR-005。

后台/失焦触发flush；可取消的正常退出请求等待flush。最新dirty修改未能保护时给出返回/继续退出选择。强制终止、掉电及OS强制退出可能丢失最后300ms或尚未提交的写入；不能声称零丢失。测试覆盖应用退出回调，不代替实际OS关机或断电实验。
