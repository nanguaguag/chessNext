# ADR-062：本机皮肤包ZIP安全导入

状态：接受（2026-11-04）

## 背景

ADR-061定义了项目本机单皮肤ZIP导出格式。E42/E48只确认源站存在ZIP/图片/文件夹入口及ZIP多皮肤说明，未实际导入；通用格式、冲突和成功边界都仍U。

## 决策

- 本片只接受本项目schema 1单皮肤包；不宣称解析任意站点ZIP。macOS以系统文件选择读取，8 MiB有界流；其它平台选择器未接入。
- 严格限制最多15个中心目录项（清单+14图片），清单64 KiB，图片总展开字节7 MiB、单张512 KiB；每图复用PNG/JPEG签名、真实解码和尺寸检查。
- 仅允许固定`skin.json`和`images/<14个固定槽位>.<png|jpg>`路径；拒绝重复目录项、目录、软链接、未知文件、路径穿越、重复槽位、未引用文件、超限声明值和SHA-256不匹配。所有清单/图片先完整验证，再展示确认。
- 导入总是生成新的本机ID；重名或本机皮肤达到64套时拒绝，不覆盖。用户确认后先安装图片、再保存皮肤目录，目录保存失败时尝试移除图片；若底层清理也失败，残留目录不列入皮肤库，可由后续清理处理。
- 导入成功后选用新皮肤；偏好写入失败时皮肤仍留在库中并显示状态，不回滚已保存皮肤。

## 后果

项目自有格式可离线往返；任意网站皮肤ZIP/文件夹导入、多套ZIP选取、源站冲突策略、非macOS文件选择和系统面板人工验收仍待办。文件格式限制先于任何文件写入。
