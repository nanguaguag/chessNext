# ADR-040：棋盘PNG不可变快照与独立二进制导出

- 状态：接受（macOS文件保存切片）
- 日期：2026-11-02
- 关联：F11、B11、B19、E34

## 背景

E34只确认参考站导出当前显示棋盘及镜像跟随，样本为1000×1100；未确认固定分辨率、取消或失败策略。产品不能使用参考图片和图形资源，也不能让UI直接选择或写文件。既有文字导出桥强制UTF8与256KB，不适合二进制图片。

## 决策

打开图片对话框时创建BoardImageSnapshot，只复制不可变Position、末步、可靠评级、当时有效的推荐/变着箭头、方向及棋盘显示偏好，不保留Session、Controller或IO。选中、合法目标和键盘焦点是瞬时输入态，不进入图片。

项目采用450×500逻辑预览、2倍编码为900×1000 PNG；这是项目固定策略，不推断参考站尺寸规则。预览冻结主题、文字比例、减少动画和显示Scope，排除交互焦点。PNG首次生成后缓存，主谱和分析后来变化不追随。

PngImage在应用边界拥有不可变字节，并限制8MB、4096边长和400万像素。PngFileExporter复用取消结果语义，但不复用文字编码限制。macOS适配器使用系统chooser，原生独立writePngAtomic先检查签名和大小，再在utility队列用ImageIO实际解码尺寸，拒绝目录/符号链接等非普通文件，最后Foundation atomic写入。退场可取消尚未开始的chooser或写入；已开始的原子写独立完成，不描述成回滚。

## 结果与边界

UI不依赖file_selector、MethodChannel或Foundation；其它平台可替换端口。macOS生产装配提供保存，其它平台显示能力不可用说明。图片复制采用独立ImageClipboard后续增量，GIF、分享、系统保存面板人工交互及其它平台writer不由本决策宣称完成。原文字writeAtomic的UTF8/256KB约束不变。
