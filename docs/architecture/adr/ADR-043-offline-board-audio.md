# ADR-043：离线棋盘反馈音效

- 状态：已采纳（2026-11-03）
- 关联：F28、B23、M4-06、E36/E37

## 背景

参考站有五类音效开关及每类的更换入口。其更换器有默认/试听/自定义导入功能，但不应将参考站资源放进产品。当前项目采用原创本地资源。

## 决策

应用层 BoardFeedbackController 监听 BoardSession 的棋子选中变化与同一文档内位置修订，经 AudioFeedbackPort 请求播放；Flutter View 不直接调用插件。走棋/选子/吃子/将军/将死五个版本化本机布尔偏好默认开。棋步声音使用互斥分类，优先级为将死>将军>吃子>普通走棋；对应特殊事件开关关闭时回退到普通走棋偏好。选子独立。每事件使用单独短音效播放器，互不截断。

音频使用 audioplayers 6.8.1 平台适配器；五条短PCM WAV由仓库中的纯Dart生成器原创生成、随Flutter bundle本机读取。声音判断以已提交棋步的父子局面为准；非法/取消输入不播放，新文档替换不发声音。播音失败捕获并静默降级，不能回滚棋谱或打断引擎。源站复合事件优先级尚未验证，本优先级是项目决策。资源、依赖版本、lock摘要和支持边界见法律清单/追踪记录。

## 已知限制

所有提示音是简单合成音，不是用户可选音效方案。自定义音源导入/删除/安全上限、试听、系统语音和非macOS真实平台仍待后续。上游macOS插件会在当前Xcode报告Swift并发隔离警告，虽非构建失败，发行前须复查。

## 验收

纯Dart控制器测试确认开关、异常隔离和新文档静音；组件测试确认设置保存；macOS集成测试真实加载assets并经原生插件启动五种合成音。该测试不替代人工主观听感或其它OS验证。
