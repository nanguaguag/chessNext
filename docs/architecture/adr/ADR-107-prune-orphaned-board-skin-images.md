# ADR-107：启动时回收未登记的棋盘皮肤图片目录

- 状态：接受（M4-76 / F21,B24）
- 日期：2026-11-05
- 需求：B24 / ADR-080、104、106

## 决策

皮肤定义清单与图片目录位于独立文件仓储；创建中断可能在清单提交前留下图片目录，删除中断可能在定义移除后留下图片。成功读取定义清单后，应用将其所有用户皮肤ID交给图片仓储，只回收格式正确的`custom-*`目录中未登记的项目。内置皮肤目录不会清理；仍登记的项目保留。包含空目录的中断创建也由目录枚举清理。若皮肤清单读取失败，跳过回收并保留所有图像，以避免把无法确认归属的数据删除。

回收失败不会改变已加载的定义或选择，控制器显示错误；图片仍保留以便后续重试。此为本机跨仓储崩溃恢复机制，不作源站文件生命周期推断。

## 验收与剩余

测试覆盖孤儿有图目录、孤儿空目录、登记自定义皮肤、内置皮肤，以及损坏profile清单不触发清理。完整验证见TRACEABILITY。扫描与删除在单目录层级逐项执行，不是跨文件系统原子提交。
