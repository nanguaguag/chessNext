# ADR-085 分析界面 AI 单步走棋

- 日期：2026-11-05
- 状态：接受（M4-53项目切片）
- 关联：F22、E71、M4-53

## 背景

E71确认参考站AI走棋设置专用于分析界面，明确与连续人机对弈和只读分析分开。参考站控件的实际搜索效果、难度预算算法、云库请求和完整操作流程仍未知。项目架构ADR-004要求难度按可解释的固定预算建模，不假设引擎支持Skill Level。

## 决策

在本机分析面板提供独立的“AI走一着”动作：以当前分析局面和当前线路为根，默认限时1000ms，单路搜索；仅当搜索期间文档epoch、局面修订、树身份均未变化且结果是合法着法时，才以引擎来源写入当前线路。思考时锁住棋盘输入，允许明确停止；导航或文档变化会停止搜索并丢弃旧结果。若连续分析原先开启，AI着法提交后在新局面恢复分析。该动作不启用人机对弈执方、不调用在线云库、不修改规则或覆盖棋谱其它分支。

此为基于现有离线引擎的项目垂直切片（P），不宣称已复刻站点难度0–20、自定义时间、最大深度、开局/残局云库或完整持久设置；这些需独立增量和更多证据。

## 验收

- 单次动作发出有限时间EngineRequest并添加合法着法，不启动连续对弈。
- 用户取消、导航到其它局面、搜索失败和无效结果均不提交旧着法，并释放输入锁。
- 原分析运行时，先停止其搜索，单步结束后在新局面恢复。
- 棋谱容量失败保留文档并给出容量状态，不伪报引擎故障。
- fake引擎测试覆盖提交、取消、导航过期和分析恢复；Widget可从分析面板触发。
