# ADR-046：走棋音效方案

- 状态：已采纳（M4-10）
- 日期：2026-11-03
- 需求：F28 / B23

## 决定

走棋事件单独持久化“音效1 / 音效2 / 随棋子皮肤”选择，其他四类事件继续使用其默认提示音。音效2为本项目生成的原创短音。`AudioplayersFeedback`按偏好加载bundle资源；`AudioSoundPreviewPort`为三种方案提供不修改当前选择的单独试听。损坏或不存在的偏好回退音效1。

自定义走棋文件仍优先播放；有自定义文件时禁用方案下拉并提示先恢复默认，避免所选内置方案与实际播放不一致。恢复默认删除该事件文件并还原音效1。现有项目仅有默认棋子外观，“随棋子皮肤”先播放音效1；待F21皮肤资源落地后再建立皮肤声音映射，不把占位映射称作皮肤联动完成。

## 证据和验证

E40观察走棋选择器三项及各自试听按钮；音效2选择关闭后重开仍checked，随后恢复音效1。吃子更换器只显示默认音效及试听。未试听源站素材，不复制它们。专项 `audio_library_test.dart` 5/5；macOS integration 3/3（内置五事件、三种走棋预览、本机自定义文件及持久化音效2）；根 `flutter test --reporter compact` 446通过/5跳过；`flutter analyze` 无问题；`flutter run -d macos` 成功启动。
