# ADR-056：本机棋子皮肤阴影控制

- 状态：已采纳（M4-20），值域/映射均为项目P；源站精确参数仍U
- 日期：2026-11-04
- 关联：F21、B24、E43

## 证据边界

E43观察到阴影档位“无/柔和/明显”，并看到方向、距离、模糊、浓淡字段；柔和状态示例为138°、6.7%、2.4%、50%。没有验证范围、步进、单位、映射算法及保存/使用结果。样例只做证据，不当成完整源站规格。

## 决策

- 按本机PieceSkin分别记忆样式、角度、距离、模糊和不透明度；旧偏好缺字段使用当前内置预设外观。
- 项目值域为角度0°–359°、距离0%–20%格宽、模糊0%–20%格宽、浓淡0%–100%。“柔和/明显”选择分别填入项目参数建议值；滑杆可独立细调。值域和预设不冒充参考站端点。
- 呈现端以棋格宽缩放距离/模糊，角度在Flutter屏幕坐标中0°向右、90°向下；浓淡映射黑色阴影alpha。默认圆章保持既有柔和投影，方章保持无投影。
- 主棋盘、局面编辑器、PNG/GIF快照读取同一不可变值。阴影不修改命中、棋谱、规则或引擎；阴影关时相应滑杆禁用。写入走PreferencesController，预设间异步读取互不覆盖。

## 验收

纯Dart测试校验边界、JSON往返、旧偏好与异步读合并；Widget测试检查设置持久化和渲染投影；快照捕获PNG/GIF冻结值。平台视觉仍以实际macOS运行记录为准。
