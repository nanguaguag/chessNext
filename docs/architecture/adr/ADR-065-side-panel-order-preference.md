# ADR-065：本机侧栏面板顺序

- 状态：接受
- 日期：2026-11-04
- 需求：F20 / B25（E50）

## 背景

参考站“操作”设置显示四类面板可上移/下移（E50，O），但源站排序是否跨重载保存未验证（U）。chessNext侧栏已由对弈、分析、复盘、候选四个独立卡片组成，当前为固定构造顺序。

## 决策

为四种面板定义稳定枚举ID，在`AppPreferences` schema 1中可选记忆完整排列；缺字段沿用当前顺序。重复、遗漏、未知面板或未来无法解释的顺序均拒绝解码，使用已有偏好仓库恢复流程，不静默截断。设置采用Material 3拖动排序，异步偏好读取与用户即时修改按既有edited-fields规则合并；写入走PreferencesController，不由视图访问存储。主侧栏从该偏好实际构造，重排不改变棋局/分析状态。

项目仅实现侧栏顺序，不宣称源站面板显隐、播放间隔、棋谱栏、快捷菜单或触摸行为已对齐。参考值、行为/持久化仍U。

## 验收

- 旧schema无字段时默认顺序不变；完整顺序序列化往返；缺项/重复项/未知项拒绝。
- 读取尚未完成时的用户排序在迟到读取后保留，并最终落盘。
- 设置拖动排序后，主界面四卡片顺序立即变化；棋树、偏好错误处理、引擎搜索不因重排改变。
- 根目录Flutter测试、静态分析和macOS Debug运行通过。
